# Περιβάλλον δοκιμών δείκτη/LUT

Το περιβάλλον δοκιμών δείκτη/LUT είναι ένας διαδραστικός χώρος εργασίας εντός του προγράμματος προβολής εικόνων Chloros, ο οποίος σας επιτρέπει να πειραματίζεστε με υπολογισμούς πολυφασματικών δεικτών και οπτικοποιήσεις χρωμάτων σε πραγματικό χρόνο. Αυτό το ισχυρό εργαλείο σας βοηθά να δοκιμάζετε διαφορετικούς δείκτες, να βελτιώνετε τα εύρη τιμών και να δημιουργείτε οπτικοποιήσεις έτοιμες για δημοσίευση χωρίς να επαναεπεξεργάζεστε ολόκληρο το σύνολο δεδομένων σας.

## Τι είναι το Index/LUT Sandbox;

### Σκοπός

Το Sandbox παρέχει:

* **Υπολογισμό δείκτη σε πραγματικό χρόνο** - Εφαρμόστε οποιονδήποτε δείκτη βλάστησης αμέσως
* **Διαδραστική ρύθμιση LUT** - Προσαρμόστε με ακρίβεια τις χρωματικές διαβαθμίσεις και τα εύρη
* **Βελτιστοποίηση ροής εργασίας** - Προσδιορίστε τις βέλτιστες ρυθμίσεις πριν από την μαζική επεξεργασία

### Sandbox έναντι επεξεργασίας έργου

**Index/LUT Sandbox (Διαδραστικό):**

* Μία εικόνα κάθε φορά
* Άμεση ανατροφοδότηση
* Πειραματικό και επαναληπτικό
* Χωρίς μόνιμες αλλαγές στα αρχεία
* Ιδανικό για εξερεύνηση και δοκιμή

**Επεξεργασία έργου (Μαζική):**

* Ολόκληρο το σύνολο δεδομένων ταυτόχρονα
* Προκαθορισμένες ρυθμίσεις
* Μόνιμα αρχεία εξόδου
* Χρονοβόρα
* Ιδανική όταν οι ρυθμίσεις έχουν οριστικοποιηθεί

{% hint style="success" %}
**Βέλτιστη ροή εργασίας**: Χρησιμοποιήστε το Sandbox για να πειραματιστείτε και να βρείτε τις βέλτιστες ρυθμίσεις δείκτη και LUT, και στη συνέχεια εφαρμόστε αυτές τις ρυθμίσεις κατά την επεξεργασία έργου για ολόκληρο το σύνολο δεδομένων σας.
{% endhint %}

## Εργασία με το Sandbox δείκτη/LUT

### Κατανόηση των προ-υπολογισμένων δεικτών

Στο Chloros, οι δείκτες μπορούν να εφαρμοστούν κατά τη διάρκεια της επεξεργασίας του έργου. Για να καθορίσετε ποιες ρυθμίσεις δείκτη και LUT θέλετε να εφαρμόσετε στις εξαγωγές, ο ευκολότερος τρόπος είναι να χρησιμοποιήσετε το Sandbox προβολής εικόνων.

Το Sandbox σας επιτρέπει να:

* **Εφαρμόζετε νέους δείκτες και χρωματικές διαβαθμίσεις (LUT)** για την οπτικοποίηση των δεδομένων
* **Προσαρμόζετε τις ρυθμίσεις οπτικοποίησης** διαδραστικά
* **Προβάλλετε** ήδη υπολογισμένες εικόνες δείκτη
* **Ελέγχετε** τις τιμές των εικονοστοιχείων σε όλα τα επίπεδα ζουμ

### Επιλογή εικόνας για την εφαρμογή δείκτη/LUT

Για να εργαστείτε με έναν δείκτη στο Sandbox του Image Viewer <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

   * RAW (Αντανάκλαση)

### Εφαρμογή ενός δείκτη σε μια εικόνα

Μόλις η εικόνα εμφανιστεί σε πλήρη οθόνη και η πλευρική γραμμή της καρτέλας **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> είναι ανοιχτή:

1. Επιλέξτε το πλαίσιο Δείκτης στο πάνω μέρος της πλευρικής γραμμής
2. Επιλέξτε το φίλτρο της κάμεράς σας από το ανοιγόμενο μενού αριστερά
3. Επιλέξτε τον επιθυμητό τύπο δείκτη από το ανοιγόμενο μενού δεξιά
4. Σύρετε τους χρωματικούς κύκλους του καναλιού φίλτρου στις θέσεις του τύπου δείκτη παρακάτω
5. Μόλις ο τύπος είναι έγκυρος, η εικόνα θα ενημερωθεί και θα εμφανίσει τις τιμές του δείκτη
6. Μετακινήστε τον κέρσορα του ποντικιού σας για να δείτε τις τιμές στη θέση του κέρσορα
7. Μεγεθύνετε την εικόνα για να δείτε μεμονωμένα εικονοστοιχεία και τις σχετικές τιμές τους

Κάθε δείκτης έχει ένα συγκεκριμένο εύρος τιμών και νόημα:

#### Παράδειγμα NDVI

```

Formula: (NIR - Red) / (NIR + Red)

For Survey3W RGN camera:
NIR = 850nm band
Red = 661nm band

Result range: -1.0 to +1.0
Typical vegetation: 0.4 to 0.9
Stressed vegetation: 0.2 to 0.4
Bare soil: 0.0 to 0.2
Water: -0.1 to 0.1
```

Για πλήρη τεκμηρίωση των τύπων δεικτών, ανατρέξτε στο [Τύποι πολυφασματικών δεικτών](../project-settings/multispectral-index-formulas.md).

## Εργασία με LUT (Πίνακες αναζήτησης)

### Τι είναι ένας LUT;

Ένας **Πίνακας αναζήτησης (LUT)** αντιστοιχίζει αριθμητικές τιμές δεικτών σε χρώματα για οπτικοποίηση:

* **Είσοδος**: Τιμή εικονοστοιχείου δείκτη (π.χ., NDVI 0,65)
* **Έξοδος**: Χρώμα RGB (π.χ., φωτεινό πράσινο)
* **Σκοπός**: Να γίνουν τα μοτίβα πιο εύκολα ορατά και ερμηνεύσιμα**LUT κλίμακας του γκρι έναντι LUT χρώματος:**

* Κλίμακα του γκρι: Επιστημονική και ουδέτερη, δείχνει τα ακατέργαστα δεδομένα
* LUT χρώματος: Διαισθητική και εντυπωσιακή, επισημαίνει μοτίβα και διαφορές

{% hint style="success" %}
**Δυνατότητα οπτικοποίησης**: Η εφαρμογή ενός LUT χρώματος σε μια εικόνα ευρετηρίου κλίμακας του γκρι καθιστά δραματικά ευκολότερη την αναγνώριση μοτίβων, ανωμαλιών και περιοχών ενδιαφέροντος με μια ματιά.
{% endhint %}

### Εφαρμογή ενός LUT σε μια εικόνα ευρετηρίου

Μόλις έχετε μια εικόνα ευρετηρίου που εμφανίζει

1. Κάντε κλικ στο <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> κουμπί &quot;+Προσθήκη LUT&quot;
2. Επιλέξτε τη χρωματική διαβάθμιση
3. Ρυθμίστε τα ελάχιστα/μέγιστα σημεία αποκοπής
4. Ρυθμίστε τη Λειτουργία Αποκοπής
5. Επιλέξτε το πλαίσιο Ευρετηρίου στην πλευρική γραμμή της καρτέλας **Προβολή Εικόνας** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> για να εφαρμόσετε το LUT

### Επιλογή χρωματικής διαβάθμισης

**Επιλογή διαβάθμισης:**

1. Στον πίνακα LUT, εντοπίστε τη**χρωματική γραμμή διαβάθμισης**

2. Τοποθετήστε το ποντίκι σας πάνω της για να δείτε τις διαθέσιμες προεπιλογές διαβάθμισης
3. Επιλέξτε την επιθυμητή διαβάθμιση
4. Η εικόνα **ενημερώνεται αμέσως** με νέα χρώματα όταν το πλαίσιο Δείκτης είναι επιλεγμένο

{% hint style="success" %}
**Βέλτιστη πρακτική**: Για δείκτες βλάστησης όπως το NDVI, η διαβάθμιση Red-Κίτρινο-Green είναι η πιο διαισθητική, καθώς ευθυγραμμίζεται με τις φυσικές χρωματικές συσχετίσεις (πράσινο=υγιής, κίτρινο=μέτρια, κόκκινο=υπό πίεση).
{% endhint %}

### Προσαρμογή κατηγοριών χρωμάτων

Το **στοιχείο ελέγχου Κατηγορίες**καθορίζει πόσα διακριτά χρωματικά βήματα εμφανίζονται στη διαβάθμισή σας:**Επιλογές αριθμού κατηγοριών:*** **2-5 κατηγορίες**: Πολύ ευρείες κατηγορίες, διακριτές ζώνες
* **6-10 κατηγορίες**: Ισορροπημένες, κατάλληλες για ταξινόμηση
* **11-20 κατηγορίες**: Ομαλές διαβαθμίσεις, συνεχής εμφάνιση
* **20+ κατηγορίες**: Σχεδόν συνεχείς, μέγιστη ομαλότητα**Πώς να ρυθμίσετε:**

1. Στον πίνακα LUT, εντοπίστε τα**τετράγωνα δειγμάτων χρωμάτων κάτω από τη γραμμή διαβάθμισης**

2. Ρυθμίστε τον αριθμό των κατηγοριών προσθέτοντας με το κουμπί +
3. Αφαιρέστε τον αριθμό των κατηγοριών κάνοντας διπλό κλικ σε ένα δείγμα χρώματος
4. Η διαβάθμιση ενημερώνεται **σε πραγματικό χρόνο** στην εικόνα**Επίδραση στην οπτικοποίηση:*** **Λιγότερες κατηγορίες** (3-5): Δημιουργεί διακριτές ζώνες, απλοποιημένη ταξινόμηση, ευκολότερη διάκριση κατηγοριών
* **Μεσαίες κατηγορίες** (6-10): Ισορροπημένη προσέγγιση, κατάλληλη για τις περισσότερες εφαρμογές
* **Περισσότερες κατηγορίες** (15-20): Ομαλές μεταβάσεις, λεπτομερείς διακυμάνσεις, φωτογραφική εμφάνιση**Πότε να το χρησιμοποιήσετε:*** **Λίγες κατηγορίες (3-5)**: Διαφάνειες παρουσίασης, χάρτες ταξινόμησης, απλές αναφορές
* **Μεσαίες κατηγορίες (6-10)**: Γενική ανάλυση, ισορροπημένες λεπτομέρειες, τυπικές αναφορές
* **Πολλές κατηγορίες (15-20)**: Επιστημονική ανάλυση, λεπτομερής επιθεώρηση, αποτελέσματα ποιότητας δημοσίευσης

### Λεπτομερής ρύθμιση των εύρων τιμών

Τα **στοιχεία ελέγχου εύρους τιμών**καθορίζουν ποιες τιμές δείκτη αντιστοιχούν σε ποια χρώματα στη διαβάθμισή σας:**Στοιχεία ελέγχου εύρους στον πίνακα LUT:*** **Ελάχιστη τιμή**: Κάτω όριο της χρωματικής κλίμακας
* **Μέγιστη τιμή**: Άνω όριο της χρωματικής κλίμακας
* **Ενδιάμεσες τιμές**: Κατανέμονται αυτόματα μεταξύ ελάχιστου και μέγιστου (με βάση τον αριθμό των κατηγοριών)

#### Ρύθμιση ελάχιστων/μέγιστων τιμών

**Για να ρυθμίσετε τα εύρη τιμών:**

1. Στον πίνακα LUT, εντοπίστε τα πεδία εισαγωγής**Ελάχιστη τιμή**και**Μέγιστη τιμή**

2. Κάντε κλικ στο πεδίο**Ελάχιστη τιμή**

3. Πληκτρολογήστε την επιθυμητή ελάχιστη τιμή (π.χ., `0.2`)
4. Πατήστε **Enter** ή κάντε κλικ έξω από το πεδίο
5. Επαναλάβετε για το πεδίο **Μέγιστη τιμή** (π.χ., `0.9`)
6. Η οπτικοποίηση **ενημερώνεται αμέσως**{% hint style="info" %}**Αυτόματη κλιμάκωση**: Όταν εφαρμόζετε για πρώτη φορά ένα LUT, το Chloros ορίζει αυτόματα το ελάχιστο/μέγιστο στο πραγματικό εύρος δεδομένων της εικόνας. Στη συνέχεια, μπορείτε να περιορίσετε αυτό το εύρος για να εστιάσετε σε συγκεκριμένα εύρη τιμών που σας ενδιαφέρουν.
{% endhint %}

**Παράδειγμα ρυθμίσεων εύρους NDVI:*** **Πλήρες εύρος**: `-1.0` έως `1.0` (εμφάνιση όλων των πιθανών τιμών)
* **Εστίαση στη βλάστηση**: `0.2` έως `0.9` (αποκλεισμός γυμνού εδάφους και νερού)
* **Μόνο υγιής βλάστηση**: `0.5` έως `0.9` (επισημάνετε μόνο τα εύρωστα φυτά)
* **Ανίχνευση στρες**: `0.2` έως `0.5` (επισημάνετε τις προβληματικές περιοχές)
* **Προσαρμοσμένο εύρος**: Προσαρμόστε με βάση τις τιμές pixel που παρατηρήσατε**Γιατί να προσαρμόσετε τα εύρη;*** **Αυξήστε την αντίθεση** στην περιοχή που σας ενδιαφέρει
* **Εξαιρέστε τις άσχετες τιμές** (π.χ. υδάτινα σώματα, γυμνό έδαφος)
* **Τυποποιήστε την οπτικοποίηση** σε πολλές εικόνες ή ημερομηνίες
* **Επισημάνετε τις λεπτές διαφορές** εντός ενός στενού εύρους τιμών

### Αποκοπή τιμών εκτός εύρους

Όταν οι τιμές των εικονοστοιχείων βρίσκονται εκτός του εύρους ελάχιστου/μέγιστου που έχετε ορίσει, μπορείτε να ελέγξετε τον τρόπο εμφάνισής τους χρησιμοποιώντας **λειτουργίες αποκοπής**.

#### **Διαθέσιμες επιλογές λειτουργιών αποκοπής:**

#### 1. Ελάχιστο και Μέγιστο

* Εικονοστοιχεία **κάτω από το ελάχιστο**→ εμφάνιση χρησιμοποιώντας το**πρώτο χρώμα** της διαβάθμισης (π.χ. κόκκινο)
* Εικονοστοιχεία **πάνω από το μέγιστο**→ εμφάνιση χρησιμοποιώντας το**τελευταίο χρώμα** της διαβάθμισης (π.χ. πράσινο)
* **Περίπτωση χρήσης**: Έμφαση στα άκρα, εμφάνιση πλήρους εύρους δεδομένων με κορεσμένα χρώματα στα όρια
* **Παράδειγμα**: Οι τιμές NDVI κάτω από 0,2 εμφανίζονται όλες κόκκινες, οι τιμές πάνω από 0,9 εμφανίζονται όλες πράσινες

#### 2. Διαφανές φόντο

* Τα εικονοστοιχεία **εκτός εύρους**γίνονται**πλήρως διαφανή*** Μόνο τα εικονοστοιχεία **εντός του εύρους** εμφανίζουν χρωματική διαβάθμιση
* **Περίπτωση χρήσης**: Επικάλυψη GIS, απομόνωση συγκεκριμένων εύρων τιμών, επισήμανση μόνο των περιοχών ενδιαφέροντος
* **Παράδειγμα**: Εμφάνιση μόνο των τιμών NDVI 0,4-0,7 με χρώμα, όλα τα υπόλοιπα διαφανή

{% hint style="warning" %}
**Περιορισμός διαφάνειας**: Τα διαφανή εικονοστοιχεία θα εμφανίζονται με το χρώμα του φόντου στο πρόγραμμα προβολής. Όταν εξάγονται κατά τη διάρκεια της επεξεργασίας, η διαφάνεια διατηρείται σε μορφή PNG αλλά όχι σε JPG.
{% endhint %}

#### 3. Φόντο δείκτη

* Τα εικονοστοιχεία **εκτός εύρους**εμφανίζονται σε**κλίμακα του γκρι** (εμφανίζοντας ακατέργαστες τιμές δείκτη)
* Τα εικονοστοιχεία **εντός εύρους**εμφανίζουν**χρωματική διαβάθμιση*** **Περίπτωση χρήσης**: Λεπτή επισήμανση, διατήρηση του πλαισίου με παράλληλη έμφαση σε περιοχές ενδιαφέροντος
* **Παράδειγμα**: Χρωματική επισήμανση της καταπονημένης βλάστησης (NDVI 0,3-0,5) με παράλληλη εμφάνιση των υγιών περιοχών σε γκρι

#### 4. Αρχικό φόντο

* Τα εικονοστοιχεία **εκτός εύρους**εμφανίζουν την**αρχική πολυφασματική εικόνα*** Τα εικονοστοιχεία **εντός εύρους**εμφανίζουν**χρωματική διαβάθμιση*** **Περίπτωση χρήσης**: Η πιο διαισθητική - συνδυάζει το φυσικό πλαίσιο της εικόνας με αναλυτική επικάλυψη χρώματος
* **Παράδειγμα**: Δείτε την πραγματική εμφάνιση του χωραφιού/καλλιέργειας με επικάλυψη περιοχών στρες με χρωματική κωδικοποίηση

### Επιλογή της σωστής λειτουργίας αποκοπής

| Λειτουργία αποκοπής              | Ιδανική για                                   | Στυλ οπτικοποίησης          |
| -------------------------- | ------------------------------------------ | ---------------------------- |
| **Ελάχιστο και Μέγιστο**    | Πλήρης εμφάνιση δεδομένων, επιστημονική ανάλυση     | Όλα τα εικονοστοιχεία χρωματισμένα           |
| **Διαφανές φόντο** | Επικαλύψεις GIS, απομόνωση συγκεκριμένων εύρων    | Χρώμα στο εύρος, κενό πέραν αυτού |
| **Φόντο δείκτη**       | Διακριτική έμφαση, διατήρηση του πλαισίου των δεδομένων  | Χρώμα στο εύρος, γκρι πέραν αυτού  |
| **Αρχικό φόντο**    | Αναφορές, παρουσιάσεις, διαισθητική ανάλυση | Χρώμα στο εύρος, φωτογραφία πέραν αυτού |

### Δημιουργία προσαρμοσμένων χρωμάτων LUT

Για πλήρη έλεγχο της οπτικοποίησής σας, μπορείτε να δημιουργήσετε **προσαρμοσμένες χρωματικές διαβαθμίσεις** επεξεργάζοντας μεμονωμένα χρωματικά σημεία.**Για να δημιουργήσετε μια προσαρμοσμένη διαβάθμιση:**

1. Στον πίνακα LUT, εντοπίστε τη**γραμμή προεπισκόπησης διαβάθμισης**

2. Αναζητήστε τα**τετράγωνα δειγμάτων χρωμάτων** κάτω από τη διαβάθμιση
3. **Κάντε κλικ σε ένα χρωματικό σημείο** για να το επιλέξετε
4. Ανοίγει ένα **εργαλείο επιλογής χρωμάτων**

5. Επιλέξτε ένα νέο χρώμα χρησιμοποιώντας:
   * **Τροχό χρωμάτων**: Οπτική επιλογή χρωμάτων
   * **Ρυθμιστικά RGB/HSV**: Ακριβής έλεγχος χρωμάτων
   * **Εισαγωγή κωδικού Hex**: Ακριβής προδιαγραφή χρώματος (π.χ., `#FF0000` για κόκκινο)
6. Κάντε κλικ εκτός του εργαλείου επιλογής χρωμάτων **για να εφαρμόσετε το νέο χρώμα**

7. Η διαβάθμιση**ενημερώνεται αμέσως** στην εικόνα**Προσθήκη ή αφαίρεση χρωματικών στάσεων:*** **Προσθήκη στάσης**: Κάντε κλικ στο εικονίδιο + για να προσθέσετε ένα νέο δείγμα στο τέλος
* **Αφαίρεση στάσης**: Κάντε διπλό κλικ στο τετράγωνο χρώματος για να αφαιρέσετε το δείγμα**Στρατηγικές προσαρμογής:*** **Αντιστροφή διαβάθμισης**: Αναστρέψτε τη σειρά των χρωμάτων για να αντιστρέψετε τη σημασία (π.χ., πράσινο=χαμηλό, κόκκινο=υψηλό)
* **Χρώματα επωνυμίας**: Ταιριάξτε την παλέτα χρωμάτων της εταιρείας σας για τις αναφορές
* **Φιλικό προς άτομα με αχρωματοψία**: Χρησιμοποιήστε συνδυασμούς πορτοκαλί-μπλε ή μωβ-κίτρινο
* **Βελτιστοποίηση εκτύπωσης**: Επιλέξτε χρώματα που λειτουργούν τόσο στην έγχρωμη όσο και στην εκτύπωση σε κλίμακα του γκρι
* **Πολλαπλά όρια**: Χρησιμοποιήστε διακριτά χρώματα σε συγκεκριμένα όρια τιμών για ταξινόμηση

{% hint style="info" %}
**Αποθήκευση προσαρμοσμένων διαβαθμίσεων**: Οι προσαρμοσμένες διαβαθμίσεις μπορούν να αποθηκευτούν και να επαναχρησιμοποιηθούν. Κάντε κλικ στο εικονίδιο αποθήκευσης στον πίνακα LUT για να διατηρήσετε τα προσαρμοσμένα χρωματικά σας σχήματα για μελλοντική χρήση.
{% endhint %}

## Διαδραστική ροή εργασίας

### Ενημερώσεις σε πραγματικό χρόνο

Όλες οι ρυθμίσεις LUT στο sandbox ενημερώνουν την εικόνα **άμεσα και διαδραστικά**:

* **Αλλαγή επιπέδου** → Η εικόνα αλλάζει αμέσως
* **Επιλογή διαβάθμισης** → Τα χρώματα ενημερώνονται αμέσως
* **Ρύθμιση εύρους τιμών** → Η αντίθεση αλλάζει σε πραγματικό χρόνο
* **Αλλαγή κατηγοριών** → Η ομαλότητα της διαβάθμισης ενημερώνεται αμέσως
* **Τροποποίηση αποκοπής** → Η εμφάνιση του φόντου αλλάζει αμέσως
* **Επεξεργασία χρωμάτων** → Η προσαρμοσμένη διαβάθμιση εφαρμόζεται αμέσως**Δεν απαιτείται κουμπί &quot;Εφαρμογή&quot;** - όλες οι αλλαγές είναι ζωντανές και διαδραστικές!

{% hint style="success" %}
**Ζωντανή ανατροφοδότηση**: Η άμεση οπτική ανατροφοδότηση σας επιτρέπει να πειραματίζεστε γρήγορα με διαφορετικές ρυθμίσεις μέχρι να βρείτε την βέλτιστη οπτικοποίηση για τις ανάγκες της ανάλυσής σας.
{% endhint %}

### Ροή εργασίας επαναληπτικής βελτίωσης

**Τυπική ροή εργασίας βελτιστοποίησης LUT:**

1.**Επιλέξτε το επίπεδο δείκτη** (π.χ., RAW (Αντανάκλαση))
2. **Εφαρμόστε δείκτη** - Επιλέξτε το φίλτρο της κάμερας και τον τύπο δείκτη, σύρετε τους χρωματιστούς κύκλους στην κατάλληλη θέση στον τύπο δείκτη
3. **Εφαρμόστε τη διαβάθμιση LUT** - Ξεκινήστε με την προεπιλογή Red-Yellow-Green
4. **Ελέγξτε τις τιμές των εικονοστοιχείων** - Μετακινήστε τον κέρσορα, σημειώστε τα εύρη τιμών
5. **Προσαρμόστε το ελάχιστο/μέγιστο** - Περιορίστε το εύρος για να εστιάσετε στη βλάστηση (π.χ., 0,2 έως 0,9)
6. **Επιλέξτε αποκοπή** - Δοκιμάστε το &quot;Original Background&quot; για το πλαίσιο
7. **Βελτιώστε τα χρώματα** - Προσαρμόστε τη διαβάθμιση αν χρειαστεί για συγκεκριμένη έμφαση
8. **Οριστικοποιήστε τις ρυθμίσεις**- Καταγράψτε τις ρυθμίσεις και αντιγράψτε τις στις Ρυθμίσεις Έργου για επεξεργασία εξαγωγής

### Επιθεώρηση τιμών εικονοστοιχείων

Η κατανόηση των πραγματικών τιμών εικονοστοιχείων είναι κρίσιμη για τον καθορισμό αποτελεσματικών εύρων LUT:**Πώς να επιθεωρήσετε τις τιμές:**

1. Οι τιμές pixel εμφανίζονται όταν στην εικόνα είναι**επιλεγμένα** είτε το πλαίσιο &quot;Index&quot; είτε και τα δύο πλαίσια &quot;Index&quot; και &quot;LUT&quot;.
2. **Μετακινήστε τον κέρσορα** πάνω από διαφορετικές περιοχές της εικόνας
3. **Παρατηρήστε τις τιμές pixel** που εμφανίζονται στη λεζάντα καθώς περνάτε τον κέρσορα
4. Μεγεθύνετε για να δείτε μεμονωμένα pixel επισημασμένα με μια κυμαινόμενη τιμή
5. **Σημειώστε** τα εύρη τιμών για διαφορετικά χαρακτηριστικά:
   * **Υγιής βλάστηση**: π.χ., NDVI 0,55-0,85
   * **Βλάστηση υπό στρες**: π.χ., NDVI 0,30-0,50
   * **Γυμνό έδαφος**: π.χ., NDVI 0,05-0,25
   * **Νερό** (εάν υπάρχει): π.χ., NDVI -0,05 έως 0,10**Χρήση τιμών εικονοστοιχείων για τον καθορισμό εύρους LUT:**Αφού ελέγξετε τις τιμές των εικονοστοιχείων, προσαρμόστε ανάλογα τις ελάχιστες/μέγιστες τιμές του LUT:**Παράδειγμα σεναρίου:*** **Παρατήρηση**: Τιμές εδάφους = 0,05-0,25, Υπό πίεση = 0,25-0,50, Υγιές = 0,50-0,85
* **Στόχος**: Οπτικοποίηση μόνο της υγείας των φυτών (εξαιρουμένου του εδάφους)
* **Ρυθμίσεις LUT**: Ελάχιστο = `0.25`, Μέγιστο = `0.85`
* **Αποκοπή**: «Αρχικό φόντο» για να δείτε το έδαφος σε φυσικό χρώμα
* **Αποτέλεσμα**: Η χρωματική διαβάθμιση εφαρμόζεται μόνο στη βλάστηση, το έδαφος εμφανίζεται όπως στην αρχική εικόνα

{% hint style="info" %}
**Δυναμικό εύρος**: Διαφορετικές καλλιέργειες, εποχές και στάδια ανάπτυξης θα έχουν διαφορετικά εύρη τιμών. Ελέγχετε πάντα τις τιμές των εικονοστοιχείων στο συγκεκριμένο σύνολο δεδομένων σας πριν ορίσετε τα εύρη LUT.
{% endhint %}

## Προσαρμοσμένοι δείκτες (Chloros+)

### Δημιουργία τύπων προσαρμοσμένων δεικτών

{% hint style="info" %}
**Πού να δημιουργήσετε**: Οι προσαρμοσμένοι δείκτες μπορούν να διαμορφωθούν στις**Ρυθμίσεις έργου** πριν από την επεξεργασία, καθώς και στην πλαϊνή στήλη του περιβάλλοντος δοκιμών του Προγράμματος προβολής εικόνων.
{% endhint %}

**Για να δημιουργήσετε έναν προσαρμοσμένο δείκτη:**

1.**Ανοίξτε τις Ρυθμίσεις έργου** (πριν από την επεξεργασία) ή την πλευρική γραμμή του Image Viewer sandbox
2. Μεταβείτε στο **αναπτυσσόμενο μενού Τύπος δείκτη**

3. Αναζητήστε την επιλογή**&quot;Προσαρμοσμένος&quot;** (πρέπει να έχετε συνδεθεί με άδεια Chloros+)
4. **Ορίστε τον τύπο σας** χρησιμοποιώντας μεταβλητές ζωνών:
   * Ονόματα ζωνών: `NIR`, `Red`, `Green`, `Blue`, `RedEdge`, κ.λπ.
   * Τελεστές: `+`, `-`, `*`, `/`, `^` (εκθέτης)
   * Συναρτήσεις: `sqrt()`, `abs()`, κ.λπ. (εάν υποστηρίζονται)
   * Παρένθεση: `()` για τη σειρά των πράξεων
5. **Ονομάστε τον δείκτη σας** (π.χ., &quot;MyIndex&quot; ή &quot;CustomNDVI&quot;)
6. **Αποθηκεύστε τη διαμόρφωση**

**Παραδείγματα προσαρμοσμένων τύπων:**

```

Modified NDVI with offset:
(NIR - Red) / (NIR + Red + 0.5)

Simple ratio:
NIR / Red

Complex multi-band:
(NIR - Red) / (NIR + Red - Blue)

Exponential index:
(NIR / Red) ^ 2
```

{% hint style="warning" %}
**Επικύρωση τύπου**: Βεβαιωθείτε ότι ο τύπος σας χρησιμοποιεί ζώνες που είναι διαθέσιμες στην κάμερά σας. Για παράδειγμα, το RedEdge είναι διαθέσιμο μόνο σε κάμερες με φίλτρο RedEdge.
{% endhint %}
