# Πλέγμα εικόνων

Αφού εισαγάγετε εικόνες σε ένα έργο, θα δείτε τις εικόνες να εμφανίζονται σε πλέγμα στην κύρια περιοχή.

## Μέγεθος μικρογραφιών

Μπορείτε να χρησιμοποιήσετε το ρυθμιστικό ζουμ στην επάνω δεξιά γωνία για να προσαρμόσετε το μέγεθος των μικρογραφιών των εικόνων. Μπορείτε επίσης να κρατήσετε πατημένα τα πλήκτρα CTRL + τροχό ποντικιού για να αλλάξετε την κλίμακα τους.

<figure><img src="../.gitbook/assets/chloros_grid_zoom.gif" alt=""><figcaption></figcaption></figure>## Κουμπιά προβολής εξαγωγής

Καθώς οι εικόνες υποβάλλονται σε επεξεργασία, θα εμφανιστούν κουμπιά στην επάνω αριστερή γωνία της περιοχής του πλέγματος. Αυτά τα κουμπιά αλλάζουν τις μικρογραφίες του πλέγματος μεταξύ διαφορετικών τύπων εικόνων:

* **JPG** - Πρωτότυπες μικρογραφίες JPG από την κάμερα
* **Στόχοι** - Εικόνες που περιέχουν ανιχνευμένους στόχους βαθμονόμησης
* **Αντανάκλαση** - Βαθμονομημένες εικόνες αντανάκλασης
* **RWA (Δείκτης/LUT)** - Υπολογισμένες πολυφασματικές εικόνες δείκτη με χρωματική κλίση LUT

Κάνοντας κλικ στις μικρογραφίες του πλέγματος εικόνων ανοίγει η [Προβολή εικόνων](opening-an-image-full-screen.md) σε πλήρη οθόνη. Εάν η λειτουργία προβολής στο πλέγμα έχει ρυθμιστεί σε μια συγκεκριμένη εξαγωγή όπως &quot;Στόχοι&quot;, όταν κάνετε κλικ στη μικρογραφία του πλέγματος θα ανοίξει η εξαγόμενη εικόνα στόχου σε πλήρη οθόνη.
