# CLI Γρήγορη εκκίνηση (pool-*)

Η μονάδα `chloros-cli` που παρέχεται ελέγχει τους αισθητήρες DAQ μέσω της **`daq pool-*`** — «λεπτούς» πελάτες HTTP που ελέγχουν τον αισθητήρα μέσω της μόνιμης ομάδας αισθητήρων του backend Chloros. Το backend διαχειρίζεται τη μεταφορά, οπότε το GUI, το CLI και τα σενάρια SDK μοιράζονται όλα ένα ενεργό χειριστή αντί να ανταγωνίζονται για τη θύρα. Ό,τι χρειάζεται ένας πελάτης είναι προσβάσιμο μέσω του `pool-*`: σύνδεση, ροή δεδομένων, καταγραφή βαθμονομημένων αρχείων `.daq` και εναλλαγή προφίλ καλυμμάτων.

Το `pool-*` είναι επίσης η **μόνη** επιφάνεια DAQ στις κυκλοφορημένες εκδόσεις. Το `chloros-cli daq --help` παραθέτει τις υποεντολές του `pool-*`, και η κλήση μιας υποεντολής DAQ απευθείας στο υλικό σε μια διαθέσιμη έκδοση οδηγεί σε έξοδο με ρητό σφάλμα που κατονομάζει το πακέτο που λείπει και σας παραπέμπει πίσω στο `pool-*` — τίποτα δεν αποτυγχάνει σιωπηλά. (Οι εντολές απευθείας πρόσβασης στο υλικό εκτελούνται μόνο από ένα αντίγραφο του πηγαίου κώδικα MAPIR· ούτε το `pip install chloros-sdk` τις παρέχει.)

***

## Προαπαιτούμενα

* **Το backend Chloros πρέπει να εκτελείται** — οι εντολές `pool-*` είναι πελάτες του HTTP, όχι προγράμματα οδήγησης υλικού. Στο Windows, ξεκινήστε την εφαρμογή επιφάνειας εργασίας Chloros (αυτή εκκινεί το backend). Στο Linux/Jetson χωρίς οθόνη, ενεργοποιήστε την υπηρεσία: `sudo systemctl enable --now chloros-backend.service`.
* **Σύνδεση στο Chloros+ (επίπεδο επί πληρωμή)**: εκτελέστε πρώτα το `chloros-cli login`. Ο έλεγχος πραγματοποιείται από την πλευρά του διακομιστή — χωρίς σύνδεση, οι εντολές αποτυγχάνουν με το `401 AUTH_REQUIRED`· στο δωρεάν επίπεδο (Iron) αποτυγχάνουν με το `403 PLAN_UPGRADE_REQUIRED`.
* Οι εντολές στοχεύουν στο `http://127.0.0.1:5000` από προεπιλογή· η οικογένεια `daq pool-*` λαμβάνει υπόψη τη μεταβλητή περιβάλλοντος `CHLOROS_BACKEND_URL` εάν το backend σας εκτελείται αλλού.

***

## Μια συνεδρία πέντε λεπτών

```bash
# 1. Connect a sensor into the backend pool (pick the line matching your model)
chloros-cli daq pool-connect                                  # smart-detect any DAQ
chloros-cli daq pool-connect --port COM3                      # DAQ-U on a specific COM port
chloros-cli daq pool-connect --mac AA:BB:CC:DD:EE:FF          # DAQ-M by BLE MAC
chloros-cli daq pool-connect --eth-host daq-e-def330.local    # DAQ-E by hostname (reliable)

# 2. List the pool — this shows the sensor_id used by every command below
chloros-cli daq pool-list

# 3. Read the most recent calibrated spectrum frame (add --json for scripting)
chloros-cli daq pool-latest --sensor-id daq-e-def330 --json

# 4. Record a calibrated .daq file for 60 seconds
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 60 \
  --device-name "field-A"

# 5. Release the sensor when done
chloros-cli daq pool-disconnect --sensor-id daq-e-def330
```

***

## `pool-connect` — Άνοιγμα ενός αισθητήρα στην ομάδα

| Παραλλαγή | Σημασία |
| --- | --- |
| `daq pool-connect` | Έξυπνη ανίχνευση: εύρεση οποιουδήποτε DAQ σε αυτόν τον υπολογιστή. |
| `daq pool-connect --port PORT` | DAQ-U σε συγκεκριμένη σειριακή θύρα (π.χ. `COM3`, `/dev/ttyUSB0`). |
| `daq pool-connect --ble` | DAQ-M μέσω BLE, αυτόματη σάρωση MAC. |
| `daq pool-connect --mac MAC` | DAQ-M σε γνωστή διεύθυνση MAC BLE (υπονοεί το `--ble`). |
| `daq pool-connect --eth-host HOST` | DAQ-E με γνωστό όνομα κεντρικού υπολογιστή ή IP — **η αξιόπιστη διαδρομή**. |
| `daq pool-connect --eth` | DAQ-E με αυτόματη ανίχνευση (mDNS, με εφεδρική λύση ARP). Δείτε την προειδοποίηση παρακάτω. |

Σημαίες ρύθμισης, όλες προαιρετικές:

| Σημαία | Σημασία |
| --- | --- |
| `--integration-time MS` / `-t MS` | Χρόνος χειροκίνητης ολοκλήρωσης σε χιλιοστά του δευτερολέπτου. |
| `--frame-avg N` / `-f N` | Μέσος όρος καρέ ανά αναφερόμενο φάσμα. |
| `--no-ae` | Απενεργοποίηση αυτόματης έκθεσης (η AE είναι ενεργοποιημένη από προεπιλογή). |
| `--no-stream` | Σύνδεση χωρίς εκκίνηση της ροής (συνέχιση αργότερα με το `pool-stream --start`). |
| `--cap-id CAP` | Προφίλ διόρθωσης ανώτατου ορίου· η προεπιλογή του backend είναι το `sunshine_cosine`. Δείτε [`pool-set-cap`](#pool-set-cap-declare-the-fitted-cap). |

{% hint style="warning" %}
**Προειδοποίηση σχετικά με την αυτόματη ανίχνευση του `--eth`.** Σε έναν κεντρικό υπολογιστή με πολλαπλές συνδέσεις (περισσότερες από μία ενεργές διεπαφές δικτύου), το *πρώτο* `pool-connect --eth` μετά την εκκίνηση μπορεί να μην επιστρέψει αποτελέσματα, ακόμη και αν ο αισθητήρας είναι σε καλή κατάσταση — η διαδικασία ανίχνευσης μπορεί να παραλείψει τη διεπαφή του αισθητήρα ενώ η κρυφή μνήμη ARP είναι κενή. Εάν το `--eth` δεν εντοπίσει τίποτα, επαναλάβετε την προσπάθεια ή παραλείψτε εντελώς την ανίχνευση χρησιμοποιώντας το `--eth-host <ip-or-hostname>`, το οποίο αποτελεί την αξιόπιστη διαδικασία σε μηχανές με πολλαπλές συνδέσεις. Το όνομα κεντρικού υπολογιστή του DAQ-E είναι `daq-e-<id>.local` (π.χ. `daq-e-def330.local`)· λειτουργεί επίσης και η απλή διεύθυνση IP του.
{% endhint %}

## `pool-list` — δείτε τι είναι συνδεδεμένο

Εμφανίζει κάθε αισθητήρα στην ομάδα του backend, συμπεριλαμβανομένου του `sensor_id` που απαιτείται από κάθε άλλη εντολή:

| Μοντέλο | Μορφή `sensor_id` | Παράδειγμα |
| --- | --- | --- |
| DAQ-U / DAQ-M | 5-οκτάδες με παύλες | `CB-7C-A8-2E-5F` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

## `pool-latest` — ανάγνωση πλαισίων φάσματος

```bash
chloros-cli daq pool-latest --sensor-id daq-e-def330 --recent 10 --json
```

Επιστρέφει το πιο πρόσφατο πλαίσιο ή τα πιο πρόσφατα πλαίσια `--recent N`· το `--json` εξάγει έξοδο αναγνώσιμη από μηχανή για τη δημιουργία σεναρίων. Τα πλαίσια είναι ραδιομετρικά βαθμονομημένη φασματική ακτινοβολία (W/m²/nm) σε πλέγμα 135 σημείων, 340–1010 nm, με το προφίλ του καλύμματος του αισθητήρα να έχει ήδη εφαρμοστεί. Για ποσοτικές τιμές ακτινοβολίας, υπολογίστε τον μέσο όρο τουλάχιστον 15 δευτερολέπτων καρέ — πρόκειται για χαρακτηριστικό του οργάνου, όχι για ελάττωμα.

## `pool-stream` — παύση ή συνέχιση της ροής δεδομένων

```bash
chloros-cli daq pool-stream --sensor-id daq-e-def330 --stop    # pause
chloros-cli daq pool-stream --sensor-id daq-e-def330 --start   # resume
```

## `pool-record` — καταγραφή αρχείου `.daq`

```bash
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 150 \
  --output ~/Documents/spectra --device-name "rooftop-A"
chloros-cli daq pool-record --sensor-id daq-e-def330 --stop
```

| Σημαία | Προεπιλογή | Σημασία |
| --- | --- | --- |
| `--duration SEC` / `-d SEC` | `0` | Διάρκεια εγγραφής σε δευτερόλεπτα· `0` σημαίνει ότι η εκτέλεση θα συνεχιστεί μέχρι να δοθεί η εντολή `--stop`. |
| `--output DIR` / `-o DIR` | `~/Documents/DAQ Live View/` | Κατάλογος εξόδου, προσδιορίζεται **στον υπολογιστή που εκτελεί το backend**. |
| `--device-name NAME` | — | Ετικέτα που αποθηκεύεται μαζί με την καταγραφή. |
| `--stop` | — | Διακοπή μιας καταγραφής που βρίσκεται σε εξέλιξη. |

{% hint style="info" %}
Η εγγραφή πραγματοποιείται στο backend, οπότε το αρχείο `.daq` αποθηκεύεται στο σύστημα αρχείων του **υπολογιστή του backend** — από προεπιλογή στο `~/Documents/DAQ Live View/` εκεί, όχι απαραίτητα εκεί όπου εκτελέσατε το CLI. Τα ονόματα αρχείων περιλαμβάνουν τον αναγνωριστικό αισθητήρα και μια χρονική σήμανση.
{% endhint %}

## `pool-set-cap` — δήλωση του τοποθετημένου καλύμματος

```bash
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id sunshine_cosine
```

Το αναγνωριστικό του καλύμματος επιλέγει το προφίλ διόρθωσης που έχει μετρηθεί στο εργοστάσιο και εφαρμόζεται σε κάθε φάσμα, και **πρέπει να ταιριάζει με το κάλυμμα που είναι φυσικά τοποθετημένο στον αισθητήρα** — ούτε ο αισθητήρας ούτε το λογισμικό μπορούν να ανιχνεύσουν το κάλυμμα από μόνα τους, και η επιλογή αποτυπώνεται σε κάθε αρχείο `.daq`. Η προεπιλογή παντού είναι το `sunshine_cosine` (κάθε DAQ διατίθεται με εγκατεστημένο το καπάκι διόρθωσης συνημιτόνου Sunshine, με σχεδιασμένη εξασθένηση ~12× — μια μη δηλωμένη αλλαγή καπακιού διορθώνει εσφαλμένα τα φάσματα κατά περίπου αυτόν τον συντελεστή).

| `--cap-id` | Διαθέσιμο σε |
| --- | --- |
| `sunshine_cosine` (προεπιλογή) | DAQ-U, DAQ-M, DAQ-E |
| `fov_15`, `fov_45`, `fov_90` | DAQ-U, DAQ-E |
| `fov_30`, `fov_60` | Μόνο DAQ-U |
| `none` | Μόνο DAQ-E — βλ. σημείωση |

Ένα αναγνωριστικό καλύμματος εκτός του συνόλου του αισθητήρα απορρίπτεται κατά τη σύνδεση με σαφές σφάλμα. Το `none` (DAQ-E) σημαίνει ότι το κάλυμμα έχει αφαιρεθεί φυσικά — εξακολουθεί να εφαρμόζει ένα εργοστασιακό γεωμετρικό προφίλ για τον εσοχή του γυάλινου διαχύτη του DAQ-E, οπότε δεν είναι μια «no-op» λειτουργία, και ένα γυμνό DAQ-E αποτελεί διαμόρφωση εργαστηρίου, όχι υποστηριζόμενη διαμόρφωση πεδίου. (Ένα γυμνό DAQ-U είναι πραγματικά «γυμνό» και δεν χρειάζεται καθόλου προφίλ διόρθωσης· το DAQ-M χρησιμοποιείται με το καπάκι Sunshine.)

## `pool-disconnect` — απελευθέρωση αισθητήρων

```bash
chloros-cli daq pool-disconnect --sensor-id daq-e-def330   # one sensor
chloros-cli daq pool-disconnect --all                      # everything in the pool
```

## Περίληψη εντολών

| Εντολή | Σκοπός |
| --- | --- |
| `daq pool-connect [--port P \| --ble \| --mac M \| --eth \| --eth-host H] [-t MS] [-f N] [--no-ae] [--no-stream] [--cap-id CAP]` | Άνοιγμα ενός αισθητήρα στην ομάδα του backend. |
| `daq pool-list` | Εμφάνιση όλων των αισθητήρων στο pool μαζί με το `sensor_id` τους. |
| `daq pool-latest --sensor-id ID [--recent N] [--json]` | Τα N πιο πρόσφατα πλαίσια φάσματος που έχουν βαθμονομηθεί. |
| `daq pool-stream --sensor-id ID [--start \| --stop]` | Επανάληψη / παύση ροής. |
| `daq pool-record --sensor-id ID [-d SEC] [-o DIR] [--device-name NAME] [--stop]` | Έναρξη / διακοπή μιας εγγραφής `.daq` (από την πλευρά του backend). |
| `daq pool-set-cap --sensor-id ID --cap-id CAP` | Αλλαγή του προφίλ διόρθωσης κορυφής κατά τη διάρκεια της εκτέλεσης. |
| `daq pool-disconnect --sensor-id ID [--all]` | Απελευθέρωση ενός αισθητήρα ή όλων. |

***

## Αντιμετώπιση προβλημάτων κατά την πρώτη σύνδεση του DAQ-E

1. Το DAQ-E δεν διαθέτει LED κατάστασης — επιβεβαιώστε την τροφοδοσία μέσω της ένδειξης PoE/σύνδεσης στο διακόπτη ή στη θύρα του εγχυτήρα και περιμένετε μερικά δευτερόλεπτα μετά την ενεργοποίηση, ώστε να εκκινήσει και να συνδεθεί στο δίκτυο.
2. Ο υπολογιστής backend πρέπει να βρίσκεται στον **ίδιο τομέα εκπομπής** με τον αισθητήρα — το mDNS δεν διαπερνά τους δρομολογητές.
3. Στο Windows, αποδεχτείτε το μήνυμα του τείχους προστασίας Defender κατά την πρώτη εκτέλεση (mDNS UDP 5353, δεδομένα DAQ-E UDP 5002, PTP UDP 319/320).
4. Ακόμα δεν υπάρχει απόκριση από το `--eth`; Χρησιμοποιήστε το `--eth-host` με το όνομα διακομιστή της μονάδας (`daq-e-<id>.local`) ή τη διεύθυνση IP — αυτή είναι η πιο αξιόπιστη μέθοδος, ειδικά σε διακομιστές με πολλαπλές συνδέσεις.
