# Γρήγορη εκκίνηση CLI (pool-*)

Οι μονάδες `chloros-cli` που παρέχονται ελέγχουν τους αισθητήρες DAQ μέσω της οικογένειας εντολών **`daq pool-*`** — απλοί πελάτες HTTP που χειρίζονται τον αισθητήρα μέσω της μόνιμης ομάδας αισθητήρων του backend του Chloros. Το backend διαχειρίζεται τη μεταφορά δεδομένων, οπότε το GUI, το CLI και τα σενάρια SDK μοιράζονται όλα ένα ενεργό χειριστή αντί να ανταγωνίζονται για τη θύρα. Όλα όσα χρειάζεται ένας πελάτης είναι προσβάσιμα μέσω του `pool-*`: σύνδεση, ροή δεδομένων, καταγραφή βαθμονομημένων αρχείων `.daq` και εναλλαγή προφίλ ορίων.

Το `pool-*` είναι η υποστηριζόμενη διεπαφή DAQ στις κυκλοφορημένες εκδόσεις. Το `chloros-cli daq --help` παραθέτει τις υποεντολές του `pool-*`, ενώ το `daq discover` / `daq list` εκτελούν την ίδια σάρωση με το `pool-discover`. Όταν μια υποεντολή DAQ για άμεση πρόσβαση στο υλικό δεν είναι διαθέσιμη, η διαδικασία τερματίζεται με ένα ρητό σφάλμα που αναφέρει το πακέτο που λείπει και σας παραπέμπει πίσω στο `pool-*` — τίποτα δεν αποτυγχάνει σιωπηλά. (Ούτε το `pip install chloros-sdk` παρέχει τις εντολές για άμεση πρόσβαση στο υλικό.)

***

## Προαπαιτούμενα

* **Το backend του Chloros πρέπει να εκτελείται** — οι εντολές `pool-*` είναι πελάτες HTTP, όχι προγράμματα οδήγησης υλικού. Στα Windows, ξεκινήστε την εφαρμογή επιφάνειας εργασίας του Chloros (αυτή εκκινεί το backend). Σε συστήματα Linux/Jetson χωρίς οθόνη, ενεργοποιήστε την υπηρεσία ως χρήστης: `sudo systemctl enable --now chloros-backend@$USER.service` (βλ. [Εγκατάσταση σε Linux](../linux/linux-installation.md#always-on-ptp-for-headless-hosts)).
* **Σύνδεση στο Chloros+ (επίπεδο επί πληρωμή)**: εκτελέστε πρώτα το `chloros-cli login`. Ο έλεγχος πραγματοποιείται από την πλευρά του διακομιστή — χωρίς σύνδεση, οι εντολές αποτυγχάνουν με το `401 AUTH_REQUIRED`· στο δωρεάν επίπεδο (Iron) αποτυγχάνουν με το `403 PLAN_UPGRADE_REQUIRED`.
* Οι εντολές στοχεύουν στο `http://127.0.0.1:5000` από προεπιλογή· η οικογένεια `daq pool-*` λαμβάνει υπόψη τη μεταβλητή περιβάλλοντος `CHLOROS_BACKEND_URL` εάν το backend σας εκτελείται αλλού.

## Μια συνεδρία πέντε λεπτών

```bash
# 1. Connect a sensor into the backend pool (pick the line matching your model)
chloros-cli daq pool-connect                                  # smart-detect any DAQ
chloros-cli daq pool-connect --port COM3                      # DAQ-U on a specific COM port
chloros-cli daq pool-connect --mac AA:BB:CC:DD:EE:FF          # DAQ-M by BLE MAC
chloros-cli daq pool-connect --eth-host daq-e-def330.local    # DAQ-E by hostname (reliable)
#    (a DAQ-M's BLE MAC is not printed anywhere: find it with `chloros-cli daq pool-discover --only ble`)

# 2. List the pool — this shows the sensor_id used by every command below
chloros-cli daq pool-list

# 3. Read the most recent calibrated spectrum frame (add --json for scripting)
chloros-cli daq pool-latest --sensor-id daq-e-def330 --json

# 4. Record a calibrated .daq file for 60 seconds
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 60 \
  --device-name "field-A"

# 5. Release the sensor when done
chloros-cli daq pool-disconnect --sensor-id daq-e-def330
```

## `pool-connect` — άνοιγμα ενός αισθητήρα στην ομάδα

| Παραλλαγή | Σημασία |
| --- | --- |
| `daq pool-connect` | Έξυπνη ανίχνευση: εύρεση οποιουδήποτε DAQ σε αυτόν τον υπολογιστή. |
| `daq pool-connect --port PORT` | DAQ-U σε συγκεκριμένη σειριακή θύρα (π.χ. `COM3`, `/dev/ttyUSB0`). |
| `daq pool-connect --ble` | DAQ-M μέσω BLE, αυτόματη σάρωση MAC. |
| `daq pool-connect --mac MAC` | DAQ-M σε γνωστή διεύθυνση MAC BLE (υπονοεί το `--ble`). |
| `daq pool-connect --eth-host HOST` | DAQ-E σε γνωστό όνομα κεντρικού υπολογιστή ή IP — **η αξιόπιστη διαδρομή**. |
| `daq pool-connect --eth` | DAQ-E με αυτόματη ανίχνευση (mDNS, με εφεδρική λύση ARP). Δείτε την προειδοποίηση παρακάτω. |

Σημαίες ρύθμισης, όλες προαιρετικές:

| Σημαία | Σημασία |
| --- | --- |
| `--integration-time MS` / `-t MS` | Χρόνος χειροκίνητης ολοκλήρωσης σε χιλιοστά του δευτερολέπτου. |
| `--frame-avg N` / `-f N` | Μέσος όρος καρέ ανά αναφερόμενο φάσμα. |
| `--no-ae` | Απενεργοποίηση αυτόματης έκθεσης (η AE είναι ενεργοποιημένη από προεπιλογή). |
| `--no-stream` | Σύνδεση χωρίς εκκίνηση της ροής (συνέχιση αργότερα με το `pool-stream --start`). |
| `--cap-id CAP` | Προφίλ διόρθωσης Cap· η προεπιλογή του backend είναι το `sunshine_cosine`. Δείτε [`pool-set-cap`](#pool-set-cap-declare-the-fitted-cap). |

Η σύνδεση ενός DAQ-E που βρίσκεται ήδη στην ομάδα με μια άλλη από τις διευθύνσεις του — το όνομα κεντρικού υπολογιστή `daq-e-<id>.local` ή την IP του — επιστρέφει την υπάρχουσα καταχώριση της ομάδας αντί να ανοίξει τη μονάδα για δεύτερη φορά.

{% hint style="warning" %}
**Προειδοποίηση σχετικά με την αυτόματη ανίχνευση του `--eth`.** Σε έναν κεντρικό υπολογιστή με πολλαπλές συνδέσεις (περισσότερες από μία ενεργές διεπαφές δικτύου), το *πρώτο* `pool-connect --eth` μετά την εκκίνηση μπορεί να μην επιστρέψει αποτελέσματα, ακόμη και αν ο αισθητήρας είναι σε καλή κατάσταση — η αναζήτηση ενδέχεται να παραλείψει τη διεπαφή του αισθητήρα ενώ η κρυφή μνήμη ARP είναι κενή. Εάν το `--eth` δεν εντοπίσει τίποτα, επαναλάβετε την προσπάθεια ή παραλείψτε εντελώς την ανίχνευση χρησιμοποιώντας το `--eth-host <ip-or-hostname>`, το οποίο αποτελεί την αξιόπιστη διαδικασία σε μηχανές με πολλαπλές συνδέσεις. Το όνομα κεντρικού υπολογιστή του DAQ-E είναι `daq-e-<id>.local` (π.χ. `daq-e-def330.local`)· λειτουργεί επίσης και η απλή διεύθυνση IP του.
{% endhint %}

## `pool-discover` — σάρωση χωρίς σύνδεση

```bash
chloros-cli daq pool-discover                  # USB, BLE and Ethernet
chloros-cli daq pool-discover --only ble       # BLE only: this is how you find a DAQ-M's MAC
chloros-cli daq pool-discover --json           # machine-readable
```

Σαρώνει για αισθητήρες στους οποίους θα μπορούσατε να συνδεθείτε και εμφανίζει τη διεύθυνση σύνδεσης, χωρίς να πραγματοποιείται σύνδεση. Το `--only` δέχεται ένα υποσύνολο, διαχωρισμένο με κόμματα, του `usb,ble,eth`· Το `--timeout SEC` ορίζει τον χρόνο σάρωσης ανά μεταφορά (προεπιλογή 5 s, περιορισμένος σε 1–20 s). Οι αισθητήρες που είναι ήδη ανοιχτοί στην ομάδα δεν εμφανίζονται στη λίστα (ένα συνδεδεμένο DAQ-M σταματά να ανακοινώνει τη διεύθυνσή του) — χρησιμοποιήστε το `pool-list` για αυτούς. Σε μια έκδοση που έχει διατεθεί, οι εντολές `chloros-cli daq discover` και `daq list` εκτελούν την ίδια σάρωση.

## `pool-list` — δείτε τι είναι συνδεδεμένο

Εμφανίζει κάθε αισθητήρα στο backend pool, συμπεριλαμβανομένου του `sensor_id` που απαιτείται από κάθε άλλη εντολή:

| Μοντέλο | Μορφή `sensor_id` | Παράδειγμα |
| --- | --- | --- |
| DAQ-U / DAQ-M | 5 οκτάδες με παύλες | `CB-7C-A8-2E-5F` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

Ένα DAQ-E του οποίου το PTP έχει απενεργοποιηθεί (η ρύθμιση αποθηκεύεται στη μονάδα) επισημαίνεται στο `pool-list` με το `!! PTP is switched OFF on this unit (saved in its flash): its timestamps are not PTP-synced.` και την εντολή που το ενεργοποιεί ξανά — βλ. [`pool-enable-ptp`](#pool-enable-ptp-switch-a-daq-es-ptp-back-on).

## `pool-latest` — ανάγνωση πλαισίων φάσματος

```bash
chloros-cli daq pool-latest --sensor-id daq-e-def330 --recent 10 --json
```

Επιστρέφει το πιο πρόσφατο πλαίσιο ή τα πιο πρόσφατα πλαίσια `--recent N`· το `--json` παράγει έξοδο αναγνώσιμη από μηχανή για χρήση σε σενάρια. Τα πλαίσια είναι ραδιομετρικά βαθμονομημένη φασματική ακτινοβολία (W/m²/nm) σε πλέγμα 135 σημείων, 340–1010 nm, με το προφίλ καλύμματος του αισθητήρα να έχει ήδη εφαρμοστεί. Για ποσοτικές τιμές ακτινοβολίας, υπολογίστε τον μέσο όρο τουλάχιστον 15 δευτερολέπτων καρέ — πρόκειται για χαρακτηριστικό του οργάνου, όχι για ελάττωμα.

## `pool-stream` — παύση ή συνέχιση της ροής δεδομένων

```bash
chloros-cli daq pool-stream --sensor-id daq-e-def330 --stop    # pause
chloros-cli daq pool-stream --sensor-id daq-e-def330 --start   # resume
```

## `pool-record` — καταγραφή αρχείου `.daq`

```bash
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 150 \
  --output ~/Documents/spectra --device-name "rooftop-A"
chloros-cli daq pool-record --sensor-id daq-e-def330 --stop
```

| Σημαία | Προεπιλογή | Σημασία |
| --- | --- | --- |
| `--duration SEC` / `-d SEC` | `0` | Διάρκεια εγγραφής σε δευτερόλεπτα· `0` σημαίνει ότι η εκτέλεση θα συνεχιστεί μέχρι να εκτελέσετε το `--stop`. |
| `--output DIR` / `-o DIR` | `~/Documents/DAQ Live View/` | Κατάλογος εξόδου. Με το backend σε αυτόν τον υπολογιστή, μια σχετική διαδρομή προσδιορίζεται με βάση το φάκελο στον οποίο εκτελέσατε την εντολή· με απομακρυσμένο backend, η διαδρομή προσδιορίζεται **στον υπολογιστή που εκτελεί το backend**. |
| `--device-name NAME` | — | Ετικέτα που αποθηκεύεται μαζί με την εγγραφή. |
| `--stop` | — | Διακοπή μιας εγγραφής που βρίσκεται σε εξέλιξη. |
| `--confirm-after SEC` | `20` | Μετά την εκκίνηση, περιμένετε έως και αυτό το χρονικό διάστημα για την εγγραφή της πρώτης σειράς και προειδοποιήστε δυνατά (`!! WARNING: no rows written after …s. This recording is producing an EMPTY file.`) εάν δεν φτάσει καμία. Το `0` απενεργοποιεί τον έλεγχο. |
| `--heartbeat SEC` | `30` | Με το `--duration`, εκτυπώστε τον αριθμό των σειρών κάθε SEC δευτερόλεπτα και προειδοποιήστε εάν σταματήσει να αυξάνεται. Το `0` τον απενεργοποιεί. |

{% hint style="info" %}
Η καταγραφή πραγματοποιείται στο backend, οπότε το αρχείο `.daq` αποθηκεύεται στο σύστημα αρχείων του **υπολογιστή του backend** — από προεπιλογή στο `~/Documents/DAQ Live View/` εκεί, όχι απαραίτητα εκεί όπου εκτελέσατε το CLI. Τα ονόματα αρχείων περιλαμβάνουν το αναγνωριστικό του αισθητήρα και μια χρονική σήμανση.
{% endhint %}

## `pool-set-cap` — δήλωση του τοποθετημένου καλύμματος

```bash
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id sunshine_cosine
```

Το αναγνωριστικό του καλύμματος επιλέγει το προφίλ διόρθωσης που έχει μετρηθεί εργοστασιακά και εφαρμόζεται σε κάθε φάσμα, και **πρέπει να ταιριάζει με το κάλυμμα που είναι φυσικά τοποθετημένο στον αισθητήρα** — ούτε ο αισθητήρας ούτε το λογισμικό μπορούν να ανιχνεύσουν το κάλυμμα από μόνα τους, και η επιλογή αποτυπώνεται σε κάθε αρχείο `.daq`. Η προεπιλογή παντού είναι το `sunshine_cosine` (κάθε DAQ διατίθεται με το καπάκι διόρθωσης συνημιτόνου Sunshine εγκατεστημένο, με απόσβεση ~12× κατά σχεδιασμό — μια μη δηλωμένη αλλαγή καπακιού διορθώνει εσφαλμένα τα φάσματα κατά περίπου αυτόν τον συντελεστή).

| `--cap-id` | Διαθέσιμο σε |
| --- | --- |
| `sunshine_cosine` (προεπιλογή) | DAQ-U, DAQ-M, DAQ-E |
| `fov_15`, `fov_45`, `fov_90` | DAQ-U, DAQ-E |
| `fov_30`, `fov_60` | Μόνο DAQ-U |
| `none` | Μόνο DAQ-E — βλ. σημείωση |

Ένα αναγνωριστικό καλύμματος εκτός του συνόλου του αισθητήρα απορρίπτεται κατά τη σύνδεση με σαφές σφάλμα. Το `none` (DAQ-E) σημαίνει ότι το κάλυμμα έχει αφαιρεθεί φυσικά — εξακολουθεί να εφαρμόζει ένα εργοστασιακό προφίλ γεωμετρίας για τον εσοχή γυάλινο διαχύτη του DAQ-E, οπότε δεν είναι μια λειτουργία χωρίς αποτέλεσμα (no-op), και ένα γυμνό DAQ-E αποτελεί διαμόρφωση εργαστηρίου, όχι υποστηριζόμενη διαμόρφωση πεδίου. (Ένα γυμνό DAQ-U είναι πραγματικά γυμνό και δεν χρειάζεται καθόλου προφίλ διόρθωσης· το DAQ-M χρησιμοποιείται με το καπάκι Sunshine.)

## `pool-disconnect` — απελευθέρωση αισθητήρων

```bash
chloros-cli daq pool-disconnect --sensor-id daq-e-def330   # one sensor
chloros-cli daq pool-disconnect --all                      # everything in the pool
```

Το `pool-disconnect` απελευθερώνει έναν αισθητήρα ανεξάρτητα από το ποιος τον άνοιξε, οπότε απελευθερώνει επίσης έναν αισθητήρα που άφησε στην ομάδα ένα σενάριο που έπαθε σφάλμα (αφού ολοκληρωθεί πρώτα η καταγραφή που γίνεται σε αυτόν). Ένας αισθητήρας που δεν βρίσκεται στην ομάδα δεν έχει τίποτα να απελευθερώσει: η εντολή εμφανίζει το μήνυμα `<sensor-id>: already released (not in the pool)` και τερματίζεται με το `0`. Μια απελευθέρωση που το backend αρνήθηκε ή δεν επιβεβαίωσε τερματίζεται με το `1`.

## `pool-enable-ptp` — επανενεργοποίηση του PTP ενός DAQ-E

```bash
chloros-cli daq pool-enable-ptp --sensor-id daq-e-def330
```

Ένα DAQ-E διατηρεί τη ρύθμιση ενεργοποίησης/απενεργοποίησης του PTP στη δική του μνήμη, οπότε μια μονάδα της οποίας το PTP έχει απενεργοποιηθεί παραμένει απενεργοποιημένη — και οι χρονικές της σημάνσεις δεν συγχρονίζονται με το PTP — έως ότου ενεργοποιηθεί ξανά. Η εντολή `pool-list` επισημαίνει μια τέτοια μονάδα και εκτυπώνει αυτήν την εντολή για αυτήν. Το Chloros δεν ενεργοποιεί ποτέ ξανά μια μονάδα από μόνο του, επειδή η απενεργοποίηση μπορεί να είναι σκόπιμη. Νέο στην έκδοση 1.3.0.

## Ρυθμίσεις συσκευής DAQ-E

```bash
chloros-cli daq pool-info --sensor-id daq-e-def330
chloros-cli daq pool-set-network --sensor-id daq-e-def330 \
  --static 192.168.1.50 --gateway 192.168.1.1
chloros-cli daq pool-set-network --sensor-id daq-e-def330 --auto
chloros-cli daq pool-set-auto-stream --sensor-id daq-e-def330 --on
chloros-cli daq pool-reboot --sensor-id daq-e-def330
chloros-cli daq pool-update-firmware --sensor-id daq-e-def330
```

`pool-info` εμφανίζει το υλικολογισμικό του αισθητήρα (και αν αυτή η έκδοση του Chloros περιλαμβάνει νεότερο), τη διεύθυνσή του και πώς την απέκτησε, την αποθηκευμένη ρύθμιση δικτύου όταν διαφέρει από την τρέχουσα, τη ροή κατά την ενεργοποίηση και το PTP. Το `pool-set-network` επανεκκινεί τον αισθητήρα για να εφαρμόσει την αλλαγή και τον επανασυνδέει με τις ρυθμίσεις που είχε· το `--no-reboot` απλώς τις αποθηκεύει. Η στατική διεύθυνση πρέπει να βρίσκεται στο δίκτυο αυτού του υπολογιστή, διαφορετικά το Chloros την απορρίπτει· το `--force` παρακάμπτει αυτόν τον περιορισμό, μόνο για έναν υπολογιστή που θα επαναδιευθυνθεί ή θα δρομολογηθεί προς αυτήν. Οι επανεκκινήσεις απορρίπτονται ενώ ο αισθητήρας καταγράφει. Το `pool-update-firmware` αντιστοιχεί στην επιλογή **Update to \<version\>**</version\> του γραφικού περιβάλλοντος χρήστη (GUI) <version\>για τη γραμμή εντολών και αποτελεί τον τρόπο ενημέρωσης ενός DAQ-E σε Linux, το οποίο δεν διαθέτει GUI. Νέο στην έκδοση 1.3.0.

## Περίληψη εντολών

| Εντολή | Σκοπός |
| --- | --- |
| `daq pool-connect [--port P \| --ble \| --mac M \| --eth \| --eth-host H] [-t MS] [-f N] [--no-ae] [--no-stream] [--cap-id CAP]` | Άνοιγμα ενός αισθητήρα στην ομάδα του backend. |
| `daq pool-discover [--only usb,ble,eth] [--timeout SEC] [--json]` | Σάρωση για αισθητήρες χωρίς σύνδεση (εντοπίζει τη διεύθυνση MAC BLE ενός DAQ-M). |
| `daq pool-list` | Εμφάνιση όλων των αισθητήρων στο pool μαζί με το `sensor_id` τους. |
| `daq pool-latest --sensor-id ID [--recent N] [--json]` | Τα N πιο πρόσφατα βαθμονομημένα πλαίσια φάσματος. |
| `daq pool-stream --sensor-id ID [--start \| --stop]` | Επανάληψη / παύση ροής δεδομένων. |
| `daq pool-record --sensor-id ID [-d SEC] [-o DIR] [--device-name NAME] [--confirm-after SEC] [--heartbeat SEC] [--stop]` | Έναρξη / διακοπή εγγραφής `.daq` (από την πλευρά του backend). |
| `daq pool-set-cap --sensor-id ID --cap-id CAP` | Αλλαγή του προφίλ διόρθωσης κορυφής κατά τη διάρκεια της εκτέλεσης. |
| `daq pool-disconnect --sensor-id ID [--all]` | Απελευθέρωση ενός αισθητήρα ή όλων. |
| `daq pool-enable-ptp --sensor-id ID` | Επανενεργοποίηση του PTP για ένα DAQ-E του οποίου το PTP είναι απενεργοποιημένο. |
| `daq pool-info --sensor-id ID [--json]` | Το υλικολογισμικό, η διεύθυνση, οι αποθηκευμένες ρυθμίσεις δικτύου, η ροή κατά την ενεργοποίηση και το PTP ενός DAQ-E. |
| `daq pool-set-network --sensor-id ID (--auto \| --static IP [--mask M] [--gateway G]) [--no-reboot] [--force]` | DHCP ή στατική διεύθυνση· επανεκκινεί και επανασυνδέει τον αισθητήρα. |
| `daq pool-set-auto-stream --sensor-id ID (--on \| --off)` | Ροή δεδομένων κατά την ενεργοποίηση. |
| `daq pool-reboot --sensor-id ID` | Επανεκκίνηση ενός DAQ-E και επανασύνδεσή του. |
| `daq pool-update-firmware --sensor-id ID` | Εγκατάσταση του firmware του DAQ-E αυτής της έκδοσης σε παλαιότερο αισθητήρα. |

## Αντιμετώπιση προβλημάτων κατά την πρώτη σύνδεση ενός DAQ-E

1. Το DAQ-E δεν διαθέτει LED κατάστασης — επιβεβαιώστε την τροφοδοσία μέσω της ένδειξης PoE/σύνδεσης στο διακόπτη ή στη θύρα του εγχυτήρα και περιμένετε μερικά δευτερόλεπτα μετά την ενεργοποίηση, ώστε να εκκινήσει και να συνδεθεί στο δίκτυο.
2. Ο κεντρικός υπολογιστής πρέπει να βρίσκεται στον **ίδιο τομέα μετάδοσης** με τον αισθητήρα — το mDNS δεν διαπερνά τους δρομολογητές.
3. Το τείχος προστασίας πρέπει να επιτρέπει την είσοδο του mDNS (UDP 5353), των δεδομένων του DAQ-E (UDP 5002) και του PTP (UDP 319/320). Το πρόγραμμα εγκατάστασης των Windows προσθέτει έναν κανόνα για αυτό, ενώ το `.deb` για Linux τα ανοίγει σε ένα `ufw` / `firewalld` που ήταν ενεργό κατά τη στιγμή της εγκατάστασης· ένα τείχος προστασίας τρίτου κατασκευαστή ή ένα που ενεργοποιήθηκε αργότερα, πρέπει να επιτρέψει την πρόσβαση σε αυτές.
4. Ακόμα τίποτα από το `--eth`; Χρησιμοποιήστε το `--eth-host` με το όνομα κεντρικού υπολογιστή της συσκευής (`daq-e-<id>.local`) ή τη διεύθυνση IP, το οποίο παρακάμπτει την αναζήτηση.
