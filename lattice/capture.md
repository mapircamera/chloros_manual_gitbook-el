# Ρυθμίσεις και τρόποι λήψης

Η λήψη στην καρτέλα «Κάμερες» ελέγχεται από ένα κόκκινο κουμπί **«Λήψη όλων»**και ένα παράθυρο**«Ρυθμίσεις λήψης»**, το οποίο καθορίζει τι παράγει το κουμπί αυτό: ποιες κάμερες συμμετέχουν, ποιους τύπους εξαγωγής αποθηκεύει κάθε κάμερα και αν το κλείστρο ενεργοποιείται μία φορά, συνεχώς ή ανά διαστήματα. Αυτή η σελίδα περιγράφει ολόκληρη τη ροή — τη διαμόρφωση, την ίδια τη λήψη, το πού αποθηκεύονται τα αρχεία στο δίσκο και πώς να τα επεξεργαστείτε εκ νέου αργότερα για να δημιουργήσετε βαθμονομημένα προϊόντα. Τα στοιχεία ελέγχου για τις κάμερες και τις συστοιχίες βρίσκονται στις [Ρυθμίσεις κάμερας](camera-settings.md).

{% hint style="info" %}
**Οι λήψεις απαιτούν ένα ανοιχτό έργο.** Η επιλογή «Λήψη όλων» και το εικονίδιο ρυθμίσεων «Λήψεις» είναι απενεργοποιημένα έως ότου ανοίξει ένα έργο («Δημιουργήστε ή ανοίξτε ένα έργο για να αποθηκεύσετε τις λήψεις»). Κάθε λήψη αποθηκεύεται στον φάκελο του έργου στο `captures/`.
{% endhint %}

## Το παράθυρο «Ρυθμίσεις λήψης»

Ανοίξτε το με το **εικονίδιο γραναζιού δίπλα στην επιλογή «Λήψη όλων»**στη λίστα καμερών της πλευρικής γραμμής ή με το κουμπί**«Άνοιγμα ρυθμίσεων λήψης…»** στο κάτω μέρος οποιουδήποτε παραθύρου ρυθμίσεων ανά κάμερα. Η κεφαλίδα φέρει την ένδειξη «Ρυθμίσεις λήψης» με ένα κουμπί επιστροφής ←.

Οι επιλογές σας εδώ — οι συμπεριλαμβανόμενες κάμερες, τα πλαίσια ελέγχου ανά τύπο και η λειτουργία λήψης — αποθηκεύονται **ανά έργο** και επαναφέρονται όταν το ανοίξετε ξανά.

### Λειτουργίες λήψης

Τρία κουμπιά λειτουργίας στο πάνω μέρος του παραθύρου:

| Λειτουργία | Τι κάνει | Υπορυθμίσεις (προεπιλογές) |
| --- | --- | --- |
| **Μονή** *(προεπιλογή)* | Μία λήψη από όλες τις επιλεγμένες κάμερες. | — |
| **Συνεχής**| Διαδοχικές λήψεις μέχρι να πληρωθεί μια συνθήκη διακοπής. | Διακοπή βάσει**Αριθμού λήψεων** (προεπιλογή 1) *ή* **Διάρκειας λήψης** (προεπιλογή 10 s; μονάδες: δευτερόλεπτα / λεπτά / ώρες / ημέρες). |
| **Διάστημα**(timelapse) | Σειρές λήψεων με χρονοδιακόπτη. |**Λήψεις / διάστημα**(προεπιλογή 1) ·**Κάθε**N μονάδες (προεπιλογή 5 δευτ.) ·**Για** N μονάδες (προεπιλογή 1 λ.). |

Στη λειτουργία «Συνεχής» ή «Διάστημα», το κουμπί «Λήψη όλων» μετατρέπεται σε κουμπί **Διακοπή (N)** κατά τη διάρκεια της λειτουργίας, μετρώντας τις λήψεις καθώς καταγράφονται.

### Επιλογή καμερών και τύπων εξαγωγής

Το κείμενο βοήθειας του παραθύρου το συνοψίζει: επιλέξτε ποιες κάμερες και τύπους εξαγωγής παράγει η λειτουργία «Λήψη όλων» — όλα είναι ενεργοποιημένα από προεπιλογή και οι επιλογές αποθηκεύονται μαζί με αυτό το έργο.

* Τα κουμπιά **Επιλογή όλων / Καμία επιλογή** ενεργοποιούν ή απενεργοποιούν ταυτόχρονα το πλαίσιο ελέγχου συμπερίληψης κάθε κάμερας.
* **Διακόπτες τύπων μαζικής εξαγωγής**(δύο σειρές κουμπιών):**Όλα σε μορφή Raw / Όλα χωρίς debayering / Όλα σε προεπισκόπηση / Όλα σε ακτινοβολία / Όλα σε ανακλαστικότητα / Όλα σε δείκτη**. Κάθε επιλογή έχει χρωματική ένδειξη τριών καταστάσεων: πράσινο ✓ = ενεργοποιημένο για κάθε κάμερα που το υποστηρίζει, πορτοκαλί – = ενεργοποιημένο για ορισμένες, γκρι = καμία. Μια επιλογή απενεργοποιείται όταν καμία συνδεδεμένη κάμερα δεν υποστηρίζει αυτόν τον τύπο. Όλες εμφανίζονται γκρι όταν είναι ενεργοποιημένη η λειτουργία «Fastest Capture».
* **Σειρές ανά κάμερα**: ένα πλαίσιο επιλογής «Συμπερίληψη», καθώς και μια αναδιπλούμενη (▸/▾) λίστα με τους εφαρμόσιμους τύπους εξαγωγής για τη συγκεκριμένη κάμερα, με ξεχωριστά πλαίσια επιλογής. Η σειρά εμφανίζει έναν αριθμό όπως «4/6».

### Τύποι εξαγωγής και ποιες κάμερες τους υποστηρίζουν

Υπάρχουν έξι τύποι εξαγωγής: **Raw, Debayered, Radiance, Reflectance, Preview, Index**. Μόνο οι ισχύοντες εμφανίζονται στη σειρά κάθε κάμερας:

| Τύπος εξαγωγής | Περιεχόμενο | RGB (FRGB) | Πολυφασματικό Bayer (FRGN/FOCN/FNGB) | Μονοχρωματικό (M3M) |
| --- | --- | --- | --- | --- |
| **Raw** | Μωσαϊκό Bayer (μονοχρωματικό: η ενιαία ζώνη) απευθείας από τον αισθητήρα | ✓ | ✓ | ✓ |
| **Debayered** | Γραμμική απομοσαϊκοποίηση (μονοχρωματικό: κλίμακα του γκρι 1 καναλιού) | ✓ | ✓ | ✓ |
| **Προεπισκόπηση** | Πλήρης αλυσίδα επεξεργασίας (ισορροπία λευκού + γάμμα σύμφωνα με το προφίλ της κάμερας· πολυφασματική: επέκταση ψευδοχρωμάτων) | ✓ | ✓ | ✓ |
| **Ακτινοβολία** | float32 W/m²/sr/nm μέσω της πλήρους ακτινομετρικής αλυσίδας | — (δεν προσφέρεται) | ✓ | ✓ |
| **Ανακλαστικότητα** | uint16 ρ (32768 = 1,0) | — (δεν παρέχεται) | ✓ — εμφανίζεται μόνο όταν η κάμερα διαθέτει αισθητήρα φωτός DAQ (δικό της ή κληρονομημένο από τη συστοιχία της) | ίδιο με το πολυφασματικό |
| **Δείκτης** | Απόδοση δείκτη βλάστησης (LUT) | — | ✓ — απαιτεί ενεργοποιημένη, μη κενή έκφραση δείκτη στην κάμερα και δεν προσφέρεται σε μέλη συνδυασμένης συστοιχίας (η συστοιχία διαθέτει έναν κοινό δείκτη) | — (ένας δείκτης απαιτεί ≥2 ζώνες· βλ. [Μονοχρωματικές κάμερες &amp; δείκτες βλάστησης](mono-indices.md)) |

Η ακτινοβολία και η ανακλαστικότητα δεν προσφέρονται ποτέ για κάμερες RGB — η ακτινοβολία ανά Bayer δεν έχει νόημα για έναν ευρυζωνικό φωτομετρικό αισθητήρα.

### Ταχύτερη λήψη

Ο διακόπτης **⚡ Ταχύτερη λήψη — μόνο ακατέργαστα δεδομένα**(πορτοκαλί όταν είναι ενεργοποιημένος) παρακάμπτει όλες τις επιλογές εξαγωγής σε**μόνο ακατέργαστα δεδομένα** — συν ένα δωρεάν σύνθετο αρχείο συνδυασμένου δείκτη για συστοιχίες — έτσι ώστε το καρέ να αποθηκεύεται όσο το δυνατόν γρηγορότερα: οι μαθηματικοί υπολογισμοί ακτινοβολίας/ανακλαστικότητας/εμφάνισης παραλείπονται εντελώς κατά τη στιγμή της λήψης.

{% hint style="info" %}
**Ένα αρχείο `.daq` εξακολουθεί να αποθηκεύεται.** Όταν έχει αντιστοιχιστεί ένας αισθητήρας φωτός, η «Ταχύτερη Λήψη» εξακολουθεί να καταγράφει την ένδειξη DAQ κατευθυνόμενης προς τα κάτω ακτινοβολίας δίπλα στα πρωτότυπα καρέ — έτσι ώστε τα προϊόντα ακτινοβολίας, ανακλαστικότητας και δείκτη να μπορούν να δημιουργηθούν αργότερα μέσω επανεπεξεργασίας (βλ. [Επανεπεξεργασία λήψεων](#re-processing-captures-into-calibrated-products)). Το Fastest Capture δεν επηρεάζει τις επιλογές σας στα πλαίσια ελέγχου: αν το απενεργοποιήσετε, αυτές επανέρχονται.
{% endhint %}

### Χειριστήρια ανά συστοιχία

Κάθε συνδεδεμένη συστοιχία διαθέτει τη δική της κάρτα ομάδας στο παράθυρο:

* **Πλαίσιο ελέγχου «Include»** (με τρεις καταστάσεις για τα μέλη) και το όνομα της συστοιχίας με τον τρόπο εμφάνισής της: «(combined | separate)».
* Πλαίσιο ελέγχου **Aligned**(προεπιλεγμένο**ενεργό**): προσαρμόζει τις εξαγωγές των μελών στο προφίλ ευθυγράμμισης της συστοιχίας, ώστε οι εξαγωγές να είναι ευθυγραμμισμένες σε επίπεδο εικονοστοιχείων μεταξύ των καμερών. Τα αρχεία Raw παραμένουν χωρίς παραμόρφωση, αλλά φέρουν τη μετασχηματισμένη πληροφορία στα μεταδεδομένα τους. (Το ίδιο το προφίλ υπολογίζεται στο [παράθυρο ρυθμίσεων συστοιχίας](camera-settings.md#alignment-co-registration-combined-only).)
* Οι σειρές των καμερών-μελών είναι ενσωματωμένες μέσα στην κάρτα.

Η κάρτα της συστοιχίας φιλοξενεί επίσης δύο συσκευές εγγραφής. Σκεφτείτε τις ως **παρακολούθηση έναντι ανάλυσης**:

| Συσκευή εγγραφής | Βαθμός | Τι καταγράφει |
| --- | --- | --- |
| **● Εγγραφή βίντεο ευρετηρίου / ■ Διακοπή εγγραφής** *(μόνο για συνδυασμένες συστοιχίες)* | **Παρακολούθηση** | Το ζωντανό σύνθετο βίντεο του συνδυασμένου ευρετηρίου στα 10 fps — 8-bit, ανάλυση προεπισκόπησης, ενσωματωμένο LUT. Απαιτεί ανοιχτό έργο και ζωντανή προβολή ροής. Εμφανίζει τα καρέ + το χρόνο που έχει παρέλθει κατά τη διάρκεια της εγγραφής. |
| **⦿ Εγγραφή ακατέργαστης ριπής / ■ Διακοπή ακατέργαστης σειράς** *(οποιαδήποτε συστοιχία)* | **Ανάλυση**| Ακατέργαστα καρέ Bayer με τον ρυθμό ζωντανής λήψης (χωρίς επεξεργασία) συν ένα αρχείο καταγραφής ανά καρέ και μετρήσεις `.daq`, σε μορφή `captures/bursts/`. Μετά από μια ριπή, εμφανίζεται ένα κουμπί**Δημιουργία βίντεο**: επανεπεξεργάζεται τη ριπή εκτός σύνδεσης σε βαθμονομημένο βίντεο — συνδυασμένος δείκτης και/ή ακτινοβολία / ανακλαστικότητα / δείκτης ανά κάμερα — συν προαιρετικά αρχεία TIFF. Η δημιουργία με συνδυασμένο δείκτη ξεκινά αυτόματα όταν σταματήσετε τη ριπή. |##

«Capture All» Πατήστε **Capture All** στη λίστα καμερών της πλευρικής γραμμής:

Κάθε συμπεριλαμβανόμενη, ορατή, μη παύση κάμερα καταγράφει με τους επιλεγμένους τύπους εξαγωγής. **Οι συστοιχίες ενεργοποιούνται ως μία συγχρονισμένη ενεργοποίηση** (μία ενιαία συγχρονισμένη ομάδα σε όλα τα μέλη — βλ. ## Πού αποθηκεύονται οι καταγραφές

Οι καταγραφές αποθηκεύονται στο ανοιχτό έργο στο `<project>/captures/`. Κάθε τύπος εξαγωγής αποθηκεύεται στον **δικό του υποφάκελο**, οπότε μια καταγραφή πολλαπλών επιπέδων δεν αναμιγνύει ποτέ τους τύπους:

```
<project>/captures/
├── raw/           capture_<ts>_SN<serial>_raw.tif
├── debayered/     capture_<ts>_SN<serial>_debayered.tif
├── radiance/      capture_<ts>_SN<serial>_radiance.tif
├── reflectance/   capture_<ts>_SN<serial>_reflectance.tif
├── preview/       capture_<ts>_SN<serial>_display.tif
├── index/         per-camera vegetation-index (LUT) render, when Index is selected
├── composite/     array foreground/background live-view composite, when produced
├── bursts/        raw-burst recordings (frames + manifest + .daq per burst)
└── *.daq          the downwelling reading matched to the capture
```

* Το `<ts>` είναι η χρονική σήμανση της λήψης και το `<serial>` ο σειριακός αριθμός της κάμερας. Οι αυτόνομες καταγραφές ονομάζονται `capture_<ts>_SN<serial>_<level>`· οι καταγραφές πίνακα από ένα συγχρονισμένο σκανδάλη ονομάζονται `sync_<ts>_SN<serial>_<level>` και **μοιράζονται μία χρονική σήμανση για όλες τις κάμερες της ομάδας** (το επίθημα «level» παραλείπεται όταν μια κάμερα αποθηκεύει μόνο ένα επίπεδο).
* **Μία ασυμμετρία που πρέπει να γνωρίζετε:** το επίπεδο οθόνης αποθηκεύεται σε φάκελο με το όνομα `preview/`, ενώ τα αρχεία διατηρούν το `_display` στο όνομά τους — ο φάκελος και το επίθημα διαφέρουν μόνο για αυτό το επίπεδο.
* Τα άγνωστα επίπεδα αποθηκεύονται σε φάκελο με το δικό τους όνομα· εάν δεν είναι δυνατή η δημιουργία υποφακέλου, το αρχείο εγγράφεται στη ρίζα των καταγραφών αντί να χαθεί.
* Τα αρχεία TIFF καταγραφής συμπιέζονται χωρίς απώλειες (DEFLATE) από προεπιλογή και περιέχουν τα πλήρη μεταδεδομένα βαθμονόμησης και επεξεργασίας **μέσα στο XMP του αρχείου** — οι καταγραφές είναι αυτοπεριγραφικές, χωρίς άλλα αρχεία «sidecar» εκτός από το `.daq`.

Αυτή είναι η ίδια διάταξη που τα αρχεία `chloros-cli lattice capture` / `array-capture` εγγράφουν στον κατάλογό τους `-o` — όπως τεκμηριώνεται στο [Αναφορά CLI § Πώς μοιάζει ένας φάκελος καταγραφών](../reference/cli-reference.md#what-a-captures-folder-looks-like).

## Επεξεργασία εκ νέου των καταγραφών σε βαθμονομημένα προϊόντα

Τα ακατέργαστα καρέ που έχουν καταγραφεί, μαζί με το αποθηκευμένο `.daq`, είναι όλα όσα χρειάζεται η ροή επεξεργασίας — γι’ αυτό το Fastest Capture είναι ασφαλές για πραγματική εργασία.

* **GUI**: προσθέστε τον φάκελο καταγραφών σε ένα έργο ([Προσθήκη αρχείων σε ένα έργο](../processing-images-gui/adding-files-to-a-project.md)) και επεξεργαστείτε όπως συνήθως.
* **CLI**: ορίστε το `process` να δείχνει προς τη**ρίζα του φακέλου «captures»**:

```bash
chloros-cli process "C:/ChlorosProjects/MyField/captures"
```

Το `process` συνήθως εισάγει μόνο τον φάκελο που ορίζετε, αλλά όταν ο φάκελος αυτός δεν περιέχει εικόνες και έχει υποφακέλους, κατεβαίνει αυτόματα — έτσι, οι υποφάκελοι των επιπέδων και τα αρχεία της ρίζας `.daq` συλλέγονται με μία κίνηση. Κάθε λήψη εισάγεται ως **ενιαία εικόνα** με τα άλλα επίπεδά της να επισυνάπτονται ως τρόποι προβολής, και όχι ως μία εικόνα ανά επίπεδο.

Η άμεση ονομασία ενός υποφακέλου επιπέδου (π.χ. `…/captures/raw/`) λειτουργεί επίσης, αλλά παραλείπει τα αρχεία της ρίζας `.daq` — αντιγράψτε τα παράλληλα όταν επαναδημιουργείτε ένα ραδιομετρικό προϊόν από το `raw/`, διαφορετικά η αντιστοίχιση της χρονικής σήμανσης δεν θα έχει τίποτα με το οποίο να συσχετιστεί.

{% hint style="warning" %}
**Η επεξεργασία ξεκινά πάντα από το `raw`.**Σε κάθε καταγραφή, το ακατέργαστο καρέ αποτελεί την πηγή της ροής επεξεργασίας· τα `debayered`, `radiance`, `reflectance` και `preview` εμφανίζονται ως τρόποι προβολής, αλλά δεν τροφοδοτούνται ποτέ πίσω μέσω του αγωγού — η επανεπεξεργασία ενός παράγωγου προϊόντος θα επανεφάρμοζε τους υπολογισμούς βινιέτας, χρώματος και ακτινοβολίας που έχουν ήδη ενσωματωθεί στα εικονοστοιχεία του, οπότε το Chloros απορρίπτεται αντί να υποβληθεί σε διπλή επεξεργασία. Οι αποδόσεις `index/` και `composite/` δεν υποβάλλονται καθόλου σε επεξεργασία (είναι εξόδους, όχι καταγραφές). Ένας φάκελος «captures» που αποθηκεύεται**χωρίς** εισαγωγές αρχείων raw εμφανίζεται κανονικά, αλλά το `process` τον παραλείπει και το επισημαίνει· Το `--input-level {raw,debayered,processed}` είναι η σκόπιμη «εξώδρομος διαφυγής» που επιβάλλει ένα σημείο εισόδου. Δείτε την [Αναφορά CLI](../reference/cli-reference.md#what-a-captures-folder-looks-like) για τα ακριβή μηνύματα παράλειψης.
{% endhint %}

Δύο ακόμη συμπεριφορές που αξίζει να γνωρίζετε κατά τη δημιουργία σεναρίων επανεπεξεργασίας:

* Μια εκτέλεση `chloros-cli process` που ζήτησε προϊόντα αλλά δεν έγραψε **κανένα προϊόν εικόνας αποτυγχάνει με εμφανή μήνυμα σφάλματος και τερματίζεται με μη μηδενικό αποτέλεσμα** — δεν θα έχετε ποτέ μια σιωπηλή κενή εκτέλεση. Οι επιτυχημένες εκτελέσεις αναφέρουν τον αριθμό των προϊόντων τους. (Μια σκόπιμη εκτέλεση μόνο με μεταδεδομένα εξακολουθεί να θεωρείται επιτυχής.)
* Οι επανεισαγόμενες επεξεργασμένες εξαγωγές δεν καταλαμβάνουν ποτέ τη θέση των ακατέργαστων δεδομένων μιας καταγραφής — τα αρχικά ακατέργαστα δεδομένα παραμένουν πάντα η πηγή του αγωγού.

## Ισοδύναμα του CLI

Όλα όσα αναφέρονται σε αυτή τη σελίδα μπορούν να εκτελεστούν χωρίς οθόνη. Οι λειτουργίες καταγραφής του GUI αντιστοιχούν άμεσα στο `chloros-cli lattice array-capture`:

| GUI | CLI |
| --- | --- |
| Ενιαία | `chloros-cli lattice array-capture` |
| Συνεχής | `array-capture --continuous [--count N] [--duration S]` |
| Κατά διαστήματα | `array-capture --interval S [--duration S]` |
| Ταχύτερη καταγραφή | `array-capture --fastest` |
| Επιλογικό πλαίσιο ευθυγράμμισης | `--aligned / --no-aligned` |
| Πλαίσια ελέγχου τύπου εξαγωγής | `--processing LEVEL` ή `--levels L1,L2,…` (προεπιλογή `all`) |
| Εγγραφή βίντεο ευρετηρίου | `chloros-cli lattice array-record` |
| Εγγραφή ακατέργαστης σειράς φωτογραφιών / Δημιουργία βίντεο | `chloros-cli lattice array-burst` / `array-build-video` |

Οι πλήρεις πίνακες σημαίας, η επιλογή λήψης με σταθεροποιημένη αυτόματη έκθεση (smart-AE) (`--smart`) και το μοντέλο σταθερού ρυθμού βρίσκονται στο [CLI Αναφορά § Λειτουργίες λήψης, συσκευές εγγραφής &amp; Επεξεργασία εκτός σύνδεσης](../reference/cli-reference.md#capture-modes-recorders--offline-reprocess).
