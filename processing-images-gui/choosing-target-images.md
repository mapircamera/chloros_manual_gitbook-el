# Επιλογή εικόνων-στόχων

Η επισήμανση των εικόνων που περιέχουν στόχους βαθμονόμησης αποτελεί ένα κρίσιμο βήμα που επιταχύνει σημαντικά τη ροή επεξεργασίας του Chloros. Με την προεπιλογή των εικόνων-στόχων, εξαλείφεται η ανάγκη το Chloros να σαρώσει κάθε εικόνα του συνόλου δεδομένων σας για στόχους βαθμονόμησης.

## Γιατί να επισημάνετε τις εικόνες-στόχους;

### Ταχύτητα επεξεργασίας

Χωρίς την επισήμανση των εικόνων-στόχων, το Chloros πρέπει:

* Να σαρώσει κάθε μεμονωμένη εικόνα στο έργο σας
* Να εκτελέσει αλγόριθμους ανίχνευσης στόχων σε κάθε εικόνα
* Να ελέγξει εκατοντάδες ή χιλιάδες εικόνες χωρίς λόγο

**Αποτέλεσμα**: Η επεξεργασία μπορεί να διαρκέσει σημαντικά περισσότερο, ειδικά για μεγάλα σύνολα δεδομένων.

### Με επισημασμένες εικόνες-στόχους

Όταν επιλέγετε τη στήλη «Στόχος» για συγκεκριμένες εικόνες:

* Το Chloros σαρώνει μόνο τις επιλεγμένες εικόνες για στόχους
* Η ανίχνευση στόχων ολοκληρώνεται πολύ πιο γρήγορα
* Ο συνολικός χρόνος επεξεργασίας μειώνεται σημαντικά

{% hint style="success" %}
**Βελτίωση ταχύτητας**: Η επισήμανση 2-3 εικόνων-στόχων σε ένα σύνολο δεδομένων 500 εικόνων μπορεί να μειώσει τον χρόνο ανίχνευσης στόχων από 30+ λεπτά σε λιγότερο από 1 λεπτό.
{% endhint %}

***

## Πώς να επισημάνετε εικόνες στόχων

### Βήμα 1: Προσδιορίστε τις εικόνες στόχων σας

Εξετάστε τις εισαγόμενες εικόνες σας στο File Browser και προσδιορίστε ποιες εικόνες περιέχουν στόχους βαθμονόμησης.

**Συνηθισμένα σενάρια:*** **Στόχος πριν τη λήψη**: Λήψη πριν την έναρξη της συνεδρίας
* **Στόχος μετά τη λήψη**: Λήψη μετά την ολοκλήρωση της συνεδρίας
* **Στόχοι εντός πεδίου**: Στόχοι τοποθετημένοι εντός της περιοχής λήψης
* **Πολλαπλοί στόχοι**: 2-3 εικόνες-στόχοι ανά συνεδρία (συνιστάται)

### Βήμα 2: Ελέγξτε τη στήλη Στόχος

Για κάθε εικόνα που περιέχει στόχο βαθμονόμησης:

1. Εντοπίστε την εικόνα στον πίνακα του File Browser
2. Βρείτε τη στήλη **Στόχος** (η στήλη στα δεξιά)
3. Κάντε κλικ στο πλαίσιο ελέγχου στη στήλη Στόχος για την εν λόγω εικόνα
4. Επαναλάβετε για όλες τις εικόνες που περιέχουν στόχους

### Βήμα 3: Επαληθεύστε την επιλογή σας

Πριν από την επεξεργασία, ελέγξτε ξανά:

* [ ] Όλες οι εικόνες με στόχους βαθμονόμησης είναι επιλεγμένες
* [ ] Δεν έχουν επιλεγεί κατά λάθος εικόνες που δεν είναι στόχοι
* [ ] Οι στόχοι είναι καθαρά ορατοί στις επιλεγμένες εικόνες

***

## Βέλτιστες πρακτικές για εικόνες στόχων

### Οδηγίες λήψης στόχων

**Χρονοδιάγραμμα:**

* Λάβετε εικόνες στόχων αμέσως πριν και κατά τη διάρκεια της συνεδρίας λήψης
* Υπό τις ίδιες συνθήκες φωτισμού με τον αισθητήρα φωτός DAQ
* Ιδανικά, καταγράψτε εικόνες στόχων όσο πιο συχνά γίνεται για τα καλύτερα αποτελέσματα. Διαφορετικά, τα δεδομένα του αισθητήρα φωτός θα χρησιμοποιηθούν για την προσαρμογή της βαθμονόμησης με την πάροδο του χρόνου.

**Θέση κάμερας:**

* Κρατήστε την κάμερα πάνω από τον στόχο έτσι ώστε να είναι κεντραρισμένη και να καταλαμβάνει περίπου το 40-60% του κέντρου της εικόνας.
* Κρατήστε την κάμερα παράλληλη/κάτω από την επιφάνεια του στόχου

**Φωτισμός:**

* Ίδιος περιβαλλοντικός φωτισμός με τον αισθητήρα φωτός DAQ
* Αποφύγετε τις σκιές στις επιφάνειες των στόχων
* Μην εμποδίζετε την πηγή φωτός με το σώμα σας, το όχημα ή τη βλάστηση
* Οι συννεφιασμένες συνθήκες παρέχουν τα πιο σταθερά αποτελέσματα

**Κατάσταση στόχου:**

* Διατηρήστε τα πάνελ στόχων καθαρά και στεγνά
* Και τα 4 πάνελ πρέπει να είναι καθαρά ορατά και χωρίς εμπόδια
* Οι στόχοι να είναι κάθετοι/κατά πάνω προς την πηγή φωτός, αν είναι δυνατόν

### Πόσες εικόνες στόχου;

**Ελάχιστο:**1 εικόνα στόχου ανά συνεδρία.**Συνιστώμενο:** 3-5 εικόνες στόχου ανά συνεδρία.**Πρόγραμμα βέλτιστων πρακτικών:**

* 3-5 εικόνες που λαμβάνονται αμέσως μετά την έναρξη της εγγραφής από τον αισθητήρα φωτός
* Περιστρέψτε την κάμερα μεταξύ των λήψεων για βέλτιστα αποτελέσματα
* Προαιρετικά: περιοδικά κατά τη διάρκεια της συνεδρίας, εάν οι συνθήκες φωτισμού αλλάζουν συνεχώς

## Εργασία με πολλαπλές κάμερες

### Ρυθμίσεις διπλής κάμερας

Εάν χρησιμοποιείτε δύο κάμερες MAPIR ταυτόχρονα (π.χ., Survey3W RGN + Survey3N OCN):

1. Λάβετε εικόνες στόχου με **και τις δύο κάμερες** ταυτόχρονα
2. Χρησιμοποιήστε τον **ίδιο φυσικό στόχο** και για τις δύο κάμερες
3. Επισημάνετε τις εικόνες στόχου για **και τους δύο τύπους καμερών** στο File Browser
4. Το Chloros θα χρησιμοποιήσει τους κατάλληλους στόχους για τη βαθμονόμηση κάθε κάμερας

### Στήλη Μοντέλου Κάμερας

Η στήλη **Μοντέλο Κάμερας** βοηθά στον προσδιορισμό του ποια εικόνες προήλθαν από ποια κάμερα:

* Survey3W\_RGN
* Survey3N\_OCN
* Survey3W\_RGB
* κ.λπ.

Χρησιμοποιήστε αυτή τη στήλη για να επαληθεύσετε ότι έχετε επισημάνει στόχους για κάθε τύπο κάμερας στο έργο σας.

***

## Ρυθμίσεις ανίχνευσης στόχων

### Ρύθμιση ευαισθησίας ανίχνευσης

Εάν το Chloros δεν ανιχνεύει σωστά τους στόχους σας, προσαρμόστε αυτές τις ρυθμίσεις στις [Ρυθμίσεις έργου](adjusting-project-settings.md):**Ελάχιστη περιοχή δείγματος βαθμονόμησης:*** **Προεπιλογή**: 25 pixel
* **Αυξήστε** εάν λαμβάνετε ψευδείς ανιχνεύσεις σε μικρά αντικείμενα
* **Μειώστε** εάν οι στόχοι δεν ανιχνεύονται**Ελάχιστη ομαδοποίηση στόχων:*** **Προεπιλογή**: 60
* **Αυξήστε** εάν οι στόχοι χωρίζονται σε πολλαπλές ανιχνεύσεις
* **Μειώστε** αν οι στόχοι με χρωματικές διακυμάνσεις δεν ανιχνεύονται πλήρως***

## Συνηθισμένα προβλήματα με τις εικόνες στόχων

### Πρόβλημα: Δεν ανιχνεύονται στόχοι

**Πιθανές αιτίες:**

* Οι εικόνες στόχων δεν έχουν επισημανθεί στο File Browser
* Ο στόχος είναι πολύ μικρός στο κάδρο (&lt; 30% της εικόνας)
* Κακός φωτισμός (σκιά, αντανάκλαση)
* Οι ρυθμίσεις ανίχνευσης στόχων είναι πολύ αυστηρές

**Λύσεις:**

1. Βεβαιωθείτε ότι η στήλη Στόχος είναι επιλεγμένη για τις σωστές εικόνες
2. Ελέγξτε την ποιότητα της εικόνας στόχου στην προεπισκόπηση
3. Επαναλάβετε τη λήψη των στόχων εάν η ποιότητα είναι κακή
4. Προσαρμόστε τις ρυθμίσεις ανίχνευσης στόχων, εάν χρειάζεται

### Πρόβλημα: Ψευδείς ανιχνεύσεις στόχων

**Πιθανές αιτίες:**

* Λευκά κτίρια, οχήματα ή κάλυψη εδάφους που εκλαμβάνονται ως στόχοι
* Φωτεινά σημεία στη βλάστηση
* Ευαισθησία ανίχνευσης πολύ χαμηλή

**Λύσεις:**

1. Επισημάνετε μόνο τις πραγματικές εικόνες στόχων για να περιορίσετε το εύρος ανίχνευσης
2. Αυξήστε την ελάχιστη περιοχή δείγματος βαθμονόμησης
3. Αυξήστε την ελάχιστη τιμή ομαδοποίησης στόχων
4. Βεβαιωθείτε ότι οι εικόνες στόχων εμφανίζουν μόνο τον στόχο (ελάχιστη ακαταστασία στο φόντο)

## Λίστα ελέγχου επαλήθευσης

Πριν ξεκινήσετε την επεξεργασία, επαληθεύστε την επιλογή των εικόνων στόχων:

* [ ] Τουλάχιστον 1 εικόνα στόχου επισημασμένη ανά συνεδρία
* [ ] Τα πλαίσια ελέγχου της στήλης «Στόχος» είναι επιλεγμένα για όλες τις εικόνες στόχων
* [ ] Οι εικόνες στόχων έχουν ληφθεί εντός του ίδιου χρονικού πλαισίου με την έρευνα
* [ ] Οι στόχοι είναι σαφώς ορατοί στην προεπισκόπηση όταν κάνετε κλικ
* [ ] Και τα 4 πάνελ βαθμονόμησης είναι ορατά σε κάθε εικόνα στόχου
* [ ] Δεν υπάρχουν σκιές ή εμπόδια στους στόχους
* [ ] Για διπλή κάμερα: Οι στόχοι έχουν επισημανθεί και για τους δύο τύπους καμερών

***

## Επεξεργασία χωρίς στόχους

### Επεξεργασία χωρίς στόχους βαθμονόμησης

Αν και δεν συνιστάται για επιστημονική εργασία, μπορείτε να επεξεργαστείτε χωρίς στόχους:

1. Αφήστε όλα τα πλαίσια ελέγχου της στήλης «Στόχος» αποεπιλεγμένα
2. **Απενεργοποιήστε** την «Βαθμονόμηση ανακλαστικότητας» στις Ρυθμίσεις έργου
3. Η διόρθωση βινιέτας θα εξακολουθήσει να εφαρμόζεται
4. Η έξοδος δεν θα βαθμονομηθεί για απόλυτη ανακλαστικότητα

{% hint style="warning" %}
**Δεν συνιστάται**: Χωρίς βαθμονόμηση ανακλαστικότητας, οι τιμές των εικονοστοιχείων αντιπροσωπεύουν μόνο σχετική φωτεινότητα, όχι επιστημονικές μετρήσεις ανακλαστικότητας. Χρησιμοποιήστε στόχους βαθμονόμησης για ακριβή, επαναλαμβανόμενα αποτελέσματα.
{% endhint %}
