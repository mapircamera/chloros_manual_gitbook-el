# Επιλογή εικόνων-στόχων

Η επισήμανση των εικόνων που περιέχουν στόχους βαθμονόμησης υποδεικνύει στο Chloros πού ακριβώς πρέπει να τις αναζητήσει. Όταν τουλάχιστον μία εικόνα είναι επιλεγμένη στη στήλη «Target», το Chloros σαρώνει **μόνο τις επιλεγμένες εικόνες** — επομένως, η επισήμανση των στόχων αποτελεί τόσο τρόπο επιτάχυνσης της επεξεργασίας όσο και μέσο για να αποφευχθεί η εσφαλμένη αναγνώριση εικόνων της έρευνας ως στόχων.

## Γιατί να επισημάνετε εικόνες-στόχους;

### Η επισήμανση ελέγχει τη σάρωση

Όταν επιλέγετε συγκεκριμένες εικόνες στη στήλη «Στόχος»:

* Το Chloros σαρώνει μόνο τις επιλεγμένες εικόνες για στόχους
* Η ανίχνευση στόχων ολοκληρώνεται πολύ πιο γρήγορα
* Οι εικόνες της αποτύπωσης δεν μπορούν να προκαλέσουν ψευδείς ανιχνεύσεις στόχων

Εάν **καμία** εικόνα δεν είναι επιλεγμένη, το Chloros επιστρέφει στη σάρωση κάθε εικόνας του έργου:

* Οι αλγόριθμοι ανίχνευσης στόχων εκτελούνται σε κάθε εικόνα
* Εκατοντάδες ή χιλιάδες εικόνες ελέγχονται άσκοπα
* Η επεξεργασία διαρκεί σημαντικά περισσότερο, ειδικά για μεγάλα σύνολα δεδομένων

{% hint style="success" %}
**Βελτίωση ταχύτητας**: Η επισήμανση 2-3 εικόνων-στόχων σε ένα σύνολο δεδομένων 500 εικόνων μπορεί να μειώσει τον χρόνο ανίχνευσης στόχων από 30+ λεπτά σε λιγότερο από 1 λεπτό.
{% endhint %}

***

## Πώς να επισημάνετε εικόνες-στόχους

### Βήμα 1: Προσδιορίστε τις εικόνες-στόχους σας

Εξετάστε τις εικόνες που έχετε εισαγάγει στο File Browser και προσδιορίστε ποιες εικόνες περιέχουν στόχους βαθμονόμησης.

**Συνηθισμένα σενάρια:*** **Στόχος πριν τη λήψη**: Λήψη πριν από την έναρξη της συνεδρίας
* **Στόχος μετά τη λήψη**: Λήφθηκε μετά την ολοκλήρωση της συνεδρίας
* **Στόχοι εντός πεδίου**: Στόχοι που τοποθετήθηκαν εντός της περιοχής λήψης
* **Πολλαπλοί στόχοι**: 2-3 εικόνες-στόχοι ανά συνεδρία (συνιστάται)

### Βήμα 2: Ελέγξτε τη στήλη «Στόχος» (<img src="../.gitbook/assets/image (33).png" alt="" data-size="original">)

Για κάθε εικόνα που περιέχει στόχο βαθμονόμησης:

1. Εντοπίστε την εικόνα στον πίνακα του File Browser
2. Βρείτε τη στήλη **Target** (η στήλη πιο δεξιά)
3. Κάντε κλικ στο πλαίσιο επιλογής στη στήλη «Στόχος» για τη συγκεκριμένη εικόνα
4. Επαναλάβετε τη διαδικασία για όλες τις εικόνες που περιέχουν στόχους

### Βήμα 3: Επαλήθευση της επιλογής σας

Πριν από την επεξεργασία, ελέγξτε ξανά:

* [ ] Όλες οι εικόνες με στόχους βαθμονόμησης είναι επιλεγμένες
* [ ] Δεν έχουν επιλεγεί κατά λάθος εικόνες που δεν είναι στόχοι
* [ ] Οι στόχοι είναι σαφώς ορατοί στις επιλεγμένες εικόνες

## LATTICE: Οι στόχοι είναι προαιρετικοί όταν μια συσκευή DAQ πραγματοποιεί καταγραφή

Για τις πολυφασματικές κάμερες LATTICE, ένας στόχος βαθμονόμησης εντός πλαισίου αποτελεί **μία από τις δύο** πιθανές αναφορές ανακλαστικότητας:

* **Στόχος εντός πλαισίου**: όταν μια επισημασμένη εικόνα-στόχος περάσει τα κριτήρια ποιότητας (QA) του Chloros, ο στόχος γίνεται η**απόλυτη αναφορά ανακλαστικότητας** για τις εικόνες γύρω του.
* **Κατευθυνόμενη προς τα κάτω ακτινοβολία του DAQ**: όταν δεν υπάρχει στόχος (ή η QA αποτυγχάνει), το Chloros υπολογίζει την ανακλαστικότητα με βάση την κατευθυνόμενη προς τα κάτω ακτινοβολία του αισθητήρα φωτός του DAQ (ρ = π·L/E). Εάν μια εγγραφή `.daq` ή DAQ-M `.csv` καλύπτει τις λήψεις σας, λαμβάνετε βαθμονομημένη ανακλαστικότητα**χωρίς καμία εικόνα-στόχο**.

Αυτή η αυτόματη συμπεριφορά είναι η προεπιλεγμένη. Στο CLI / SDK αντιστοιχεί στο `--reflectance-source auto`· μπορείτε επίσης να επιβάλετε το `target` (αυστηρό — χωρίς υποκατάσταση DAQ) ή το `daq` (με προτεραιότητα στο DAQ). Δείτε την [Αναφορά CLI](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral).

**Γεωμετρίες στόχων LATTICE**: εκτός από την κλασική ανίχνευση πάνελ που χρησιμοποιείται για το Survey3, η επεξεργασία LATTICE υποστηρίζει**στόχους με σήμανση ArUco**,**στόχους σταθερής περιοχής ενδιαφέροντος (ROI)**και**στόχους ταινίας**, οι οποίοι διαμορφώνονται ανά έργο. Οι σαρώσεις**μετρημένης** ανακλαστικότητας στόχου ανά μονάδα μπορούν να παρασχεθούν ανά σειριακό αριθμό (CLI: `--target-reflectance-dir`, ένα `<serial>.csv` ανά μονάδα στόχου), με τα ονομαστικά φάσματα T3/T4P ως εφεδρικά.

{% hint style="info" %}
**Μονάδα F988**: Η ανακλαστικότητα της F988 βαθμονομείται χρησιμοποιώντας έναν πίνακα ανακλαστικότητας εντός σκηνής: η ζώνη βρίσκεται πέρα από το βαθμονομημένο εύρος του αισθητήρα φωτός DAQ, οπότε το Chloros εφαρμόζει την πιο πρόσφατη καταγραφή του πίνακα και τη διατηρεί μεταξύ των παρατηρήσεων του πίνακα. Εάν μια ενότητα F988 υποβληθεί σε επεξεργασία μόνο με DAQ, το Chloros απορρίπτει την ανακλαστικότητα βάσει DAQ για τη συγκεκριμένη ζώνη (λόγος παράλειψης `dls-uncalibrated-band-988`) — η ροή εργασίας με πάνελ είναι η υποστηριζόμενη μέθοδος.
{% endhint %}

## Βέλτιστες πρακτικές για εικόνες στόχου

### Οδηγίες λήψης εικόνων στόχου

**Χρονοδιάγραμμα:**

* Λάβετε εικόνες στόχου αμέσως πριν και καθ’ όλη τη διάρκεια της συνεδρίας λήψης
* Υπό τις ίδιες συνθήκες φωτισμού με τον αισθητήρα φωτός DAQ
* Ιδανικά, καταγράψτε εικόνες στόχου όσο πιο συχνά γίνεται για βέλτιστα αποτελέσματα. Διαφορετικά, τα δεδομένα του αισθητήρα φωτός θα χρησιμοποιηθούν για την προσαρμογή της βαθμονόμησης με την πάροδο του χρόνου.

**Θέση κάμερας:**

* Κρατήστε την κάμερα πάνω από τον στόχο, έτσι ώστε να είναι κεντραρισμένος και να καταλαμβάνει περίπου το 40-60% του κέντρου της εικόνας.
* Διατηρήστε την κάμερα παράλληλη ή κάθετα προς την επιφάνεια του στόχου

**Φωτισμός:**

* Ίδιος περιβαλλοντικός φωτισμός με αυτόν του αισθητήρα φωτός του συστήματος DAQ
* Αποφύγετε τις σκιές στις επιφάνειες του στόχου
* Μην εμποδίζετε την πηγή φωτός με το σώμα σας, το όχημα ή τη βλάστηση
* Οι συννεφιασμένες συνθήκες παρέχουν τα πιο σταθερά αποτελέσματα

**Κατάσταση στόχου:**

* Διατηρήστε τα πάνελ του στόχου καθαρά και στεγνά
* Όλα τα πάνελ του στόχου σας (π.χ. και τα 4 σε ένα T4) πρέπει να είναι καθαρά ορατά και χωρίς εμπόδια
* Οι στόχοι πρέπει να βρίσκονται κάθετα/κατ' ευθείαν κάτω από την πηγή φωτός, εάν είναι δυνατόν

### Πόσες εικόνες στόχου;

**Ελάχιστο:**1 εικόνα στόχου ανά συνεδρία.**Συνιστώμενο:** 3-5 εικόνες στόχου ανά συνεδρία.**Βέλτιστο πρόγραμμα:**

* 3-5 εικόνες που λαμβάνονται αμέσως μετά την έναρξη της καταγραφής από τον αισθητήρα φωτός
* Εναλλάξτε τη θέση της κάμερας μεταξύ των λήψεων για βέλτιστα αποτελέσματα
* Προαιρετικά: περιοδικά κατά τη διάρκεια της συνεδρίας, εάν οι συνθήκες φωτισμού αλλάζουν συνεχώς

## Χρήση πολλαπλών καμερών

### Διαμορφώσεις με δύο κάμερες

Εάν χρησιμοποιείτε ταυτόχρονα δύο κάμερες MAPIR (π.χ., Survey3W RGN + Survey3N OCN):

1. Λάβετε εικόνες στόχου με **και τις δύο κάμερες** ταυτόχρονα
2. Χρησιμοποιήστε τον **ίδιο φυσικό στόχο** και για τις δύο κάμερες
3. Επισημάνετε τις εικόνες-στόχους για **και τους δύο τύπους καμερών** στο File Browser
4. Το Chloros θα χρησιμοποιήσει τους κατάλληλους στόχους για τη βαθμονόμηση κάθε κάμερας

### Στήλη «Μοντέλο κάμερας»

Η στήλη **«Μοντέλο κάμερας»** βοηθά στον προσδιορισμό του ποια εικόνα προέρχεται από ποια κάμερα:

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* κ.λπ.

Χρησιμοποιήστε αυτή τη στήλη για να επαληθεύσετε ότι έχετε επισημάνει στόχους για κάθε τύπο κάμερας στο έργο σας.

## Ρυθμίσεις ανίχνευσης στόχων

### Ρύθμιση της ευαισθησίας ανίχνευσης

Εάν το Chloros δεν ανιχνεύει σωστά τους στόχους σας, προσαρμόστε αυτές τις ρυθμίσεις στις [Ρυθμίσεις έργου](adjusting-project-settings.md):**Ελάχιστη περιοχή δείγματος βαθμονόμησης (px):*** **Προεπιλογή**: 25 εικονοστοιχεία
* **Αυξήστε** την τιμή εάν παρατηρείτε ψευδείς ανιχνεύσεις σε μικρά αντικείμενα
* **Μειώστε** την τιμή εάν οι στόχοι δεν ανιχνεύονται**Ελάχιστη ομαδοποίηση στόχων (0-100):*** **Προεπιλογή**: 60
* **Αυξήστε** αν οι στόχοι χωρίζονται σε πολλαπλές ανιχνεύσεις
* **Μειώστε** αν οι στόχοι με χρωματικές διακυμάνσεις δεν ανιχνεύονται πλήρως

{% hint style="info" %}
**Συμβουλή για το CLI**: Το `chloros-cli process` δέχεται τους ίδιους ρυθμιστές (`--min-target-size`, `--target-clustering`), ενώ η σημαία του `--target`/`--targets` επισημαίνει έναν ολόκληρο φάκελο εισόδου ως «μόνο για πίνακα στόχων». Δείτε την [Αναφορά CLI](../reference/cli-reference.md).
{% endhint %}

## Συνηθισμένα προβλήματα με τις εικόνες-στόχους

### Πρόβλημα: Δεν εντοπίστηκαν στόχοι

**Πιθανές αιτίες:**

* Οι εικόνες-στόχοι δεν έχουν επισημανθεί στο File Browser
* Ο στόχος είναι πολύ μικρός στο κάδρο (< 30% της εικόνας)
* Κακός φωτισμός (σκιές, αντανακλάσεις)
* Οι ρυθμίσεις ανίχνευσης στόχων είναι πολύ αυστηρές

**Λύσεις:**

1. Βεβαιωθείτε ότι η στήλη «Target» είναι επιλεγμένη για τις σωστές εικόνες
2. Ελέγξτε την ποιότητα της εικόνας-στόχου στην προεπισκόπηση
3. Λάβετε εκ νέου εικόνες των στόχων εάν η ποιότητα είναι κακή
4. Προσαρμόστε τις ρυθμίσεις ανίχνευσης στόχων, εάν χρειάζεται

### Πρόβλημα: Ψευδείς ανιχνεύσεις στόχων

**Πιθανές αιτίες:**

* Λευκά κτίρια, οχήματα ή κάλυψη εδάφους που εκλαμβάνονται εσφαλμένα ως στόχοι
* Φωτεινά σημεία στη βλάστηση
* Ευαισθησία ανίχνευσης πολύ χαμηλή

**Λύσεις:**

1. Επιλέξτε μόνο τις πραγματικές εικόνες στόχων — μόνο οι επιλεγμένες εικόνες θα σαρωθούν
2. Αυξήστε την ελάχιστη έκταση δείγματος βαθμονόμησης
3. Αυξήστε την ελάχιστη τιμή ομαδοποίησης στόχων
4. Βεβαιωθείτε ότι οι εικόνες στόχων εμφανίζουν μόνο τον στόχο (ελάχιστη ακαταστασία στο φόντο)

## Λίστα ελέγχου επαλήθευσης

Πριν ξεκινήσετε την επεξεργασία, επαληθεύστε την επιλογή των εικόνων στόχων:

* [ ] Έχει επισημανθεί τουλάχιστον 1 εικόνα στόχου ανά συνεδρία (ή, για το LATTICE, μια εγγραφή `.daq`/`.csv` που καλύπτει τη συνεδρία)
* [ ] Τα πλαίσια ελέγχου της στήλης «Στόχος» είναι επιλεγμένα για όλες τις εικόνες-στόχους
* [ ] Οι εικόνες-στόχοι έχουν ληφθεί εντός του ίδιου χρονικού πλαισίου με την έρευνα
* [ ] Οι στόχοι είναι σαφώς ορατοί στην προεπισκόπηση όταν γίνεται κλικ πάνω τους
* [ ] Όλα τα πάνελ βαθμονόμησης είναι ορατά σε κάθε εικόνα-στόχο
* [ ] Δεν υπάρχουν σκιές ή εμπόδια πάνω στους στόχους
* [ ] Για διπλή κάμερα: Οι στόχοι έχουν επισημανθεί και για τους δύο τύπους καμερών

## Επεξεργασία χωρίς στόχους

### LATTICE: Με εγγραφή DAQ

Εάν ένας αισθητήρας φωτός DAQ κατέγραψε την ακτινοβολία προς τα κάτω κατά τη διάρκεια των λήψεων LATTICE, δεν απαιτείται στόχος:

1. Εισαγάγετε το αρχείο `.daq` (ή DAQ-M `.csv`) με τις εικόνες
2. Αφήστε τη στήλη «Στόχος» χωρίς επιλογή
3. Η ανακλαστικότητα υπολογίζεται αυτόματα από την αναφορά κατερχόμενης ακτινοβολίας του DAQ
4. Η ακτινοφάνεια δεν χρειάζεται ποτέ στόχο ή DAQ — προέρχεται αποκλειστικά από την εργοστασιακή ραδιομετρική βαθμονόμηση της κάμερας

### Επεξεργασία χωρίς καμία αναφορά

Μπορείτε επίσης να επεξεργαστείτε χωρίς στόχους και χωρίς DAQ:

1. Αφήστε όλα τα πλαίσια ελέγχου της στήλης «Στόχος» αποεπιλεγμένα
2. **Απενεργοποιήστε** την επιλογή «Βαθμονόμηση ανακλαστικότητας / ισορροπία λευκού» στις Ρυθμίσεις έργου — η ανίχνευση στόχων παραλείπεται τότε εντελώς
3. Η διόρθωση βινιέτας θα εξακολουθήσει να εφαρμόζεται
4. Η έξοδος δεν θα βαθμονομηθεί για απόλυτη ανακλαστικότητα (το LATTICE multispectral εξακολουθεί να εξάγει προϊόντα χωρίς απο-bayering, προεπισκόπησης και ακτινοβολίας)

{% hint style="warning" %}
**Δεν συνιστάται για επιστημονική εργασία με το Survey3**: Χωρίς βαθμονόμηση ανακλαστικότητας, οι τιμές των εικονοστοιχείων του Survey3 αντιπροσωπεύουν μόνο σχετική φωτεινότητα, όχι επιστημονικές μετρήσεις ανακλαστικότητας. Χρησιμοποιήστε στόχους βαθμονόμησης (ή, για το LATTICE, έναν αισθητήρα φωτός DAQ) για ακριβή και επαναλήψιμα αποτελέσματα.
{% endhint %}
