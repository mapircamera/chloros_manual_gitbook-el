# Έναρξη της επεξεργασίας

Αφού εισαγάγετε τις εικόνες σας, επισημάνετε τους στόχους βαθμονόμησης και διαμορφώσετε τις ρυθμίσεις του έργου σας, είστε έτοιμοι να ξεκινήσετε την επεξεργασία. Αυτή η σελίδα σας καθοδηγεί στη διαδικασία εκκίνησης της ροής επεξεργασίας Chloros.

## Λίστα ελέγχου πριν την επεξεργασία

Πριν κάνετε κλικ στο κουμπί «Έναρξη», βεβαιωθείτε ότι όλα είναι έτοιμα:

* [ ] **Αρχεία εισαγμένα** - Όλες οι εικόνες εμφανίζονται στο File Browser
* [ ] **Εικόνες-στόχοι επισημασμένες** - Η στήλη «Στόχος» έχει επιλεγεί για τις εικόνες βαθμονόμησης
* [ ] **Μοντέλα κάμερας ανιχνευμένα** - Η στήλη «Μοντέλο κάμερας» εμφανίζει τις σωστές κάμερες
* [ ] **Ρυθμίσεις διαμορφωμένες** - Οι ρυθμίσεις του έργου έχουν ελεγχθεί και προσαρμοστεί
* [ ] **Επιλεγμένοι δείκτες** - Προστέθηκαν οι επιθυμητοί πολυφασματικοί δείκτες (εάν απαιτείται)
* [ ] **Επιλεγμένη μορφή εξαγωγής** - Μορφή εξόδου κατάλληλη για τη ροή εργασίας σας

{% hint style="info" %}
**Συμβουλή**: Κάντε κλικ σε μερικές εικόνες στο File Browser για να βεβαιωθείτε ότι φορτώθηκαν σωστά πριν από την επεξεργασία.
{% endhint %}

***

## Έναρξη της επεξεργασίας

### Εντοπίστε το κουμπί «Έναρξη»

Το κουμπί «Έναρξη/Αναπαραγωγή» βρίσκεται στην επάνω γραμμή κεφαλίδας του Chloros:

* Θέση: Κέντρο επάνω μέρος του παραθύρου
* Εικονίδιο: **Κουμπί «Αναπαραγωγή/Έναρξη»** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
* Κατάσταση: Το κουμπί είναι ενεργοποιημένο (φωτεινό) όταν είναι έτοιμο για επεξεργασία

### Κάντε κλικ για να ξεκινήσετε

1. Κάντε κλικ στο **κουμπί Αναπαραγωγή/Έναρξη** στην επάνω γραμμή κεφαλίδας
2. Η επεξεργασία ξεκινά αμέσως
3. Το κουμπί απενεργοποιείται (εμφανίζεται γκρι) κατά τη διάρκεια της επεξεργασίας
4. Η γραμμή προόδου ενημερώνεται, δείχνοντας την κατάσταση της επεξεργασίας

{% hint style="success" %}
**Η επεξεργασία ξεκίνησε**: Μόλις κάνετε κλικ, το Chloros χειρίζεται αυτόματα όλα τα βήματα της επεξεργασίας - ανίχνευση στόχου, αποσυμπίεση, βαθμονόμηση, υπολογισμός δείκτη και εξαγωγή.
{% endhint %}

## Κατανόηση των τρόπων επεξεργασίας

Το Chloros λειτουργεί σε δύο διαφορετικές λειτουργίες επεξεργασίας, ανάλογα με την άδεια χρήσης σας:

### Δωρεάν λειτουργία (Διαδοχική επεξεργασία)

**Διαθέσιμη σε όλους τους χρήστες**

**Πώς λειτουργεί:**

* Επεξεργάζεται τις εικόνες μία κάθε φορά, διαδοχικά
* Λειτουργία μονού νήματος
* Χαμηλότερη χρήση μνήμης

**Η γραμμή προόδου δείχνει 2 στάδια:**

1.**Ανίχνευση στόχου** - Σάρωση για στόχους βαθμονόμησης
2. **Επεξεργασία** - Εφαρμογή βαθμονόμησης και εξαγωγή εικόνων**Χρόνος επεξεργασίας:**

* Πολύ πιο αργός από τον παράλληλο τρόπο λειτουργίας του Chloros+
* Κατάλληλος για μικρά έως μεσαία σύνολα δεδομένων (&lt; 200 εικόνες)

### Λειτουργία Chloros+ (Παράλληλη επεξεργασία)

**Απαιτείται άδεια χρήσης Chloros+**

**Πώς λειτουργεί:**

* Επεξεργάζεται πολλαπλές εικόνες ταυτόχρονα χρησιμοποιώντας έναν [αγωγό επεξεργασίας 4-thread](../processing-architecture/processing-pipeline.md)
* Η [Δυναμική Προσαρμογή Υπολογιστικής Ισχύος](../processing-architecture/dynamic-compute-adaptation.md) επιλέγει αυτόματα τη βέλτιστη στρατηγική για το υλικό σας
* Επιτάχυνση GPU (CUDA) με κάρτες γραφικών NVIDIA (επιτραπέζιους υπολογιστές και Jetson)
* Κλιμακώνεται από ένα Jetson Nano (1 worker) έως έναν επιτραπέζιο υπολογιστή με GPU 12GB+ (3-4 workers)

**Η γραμμή προόδου εμφανίζει 4 στάδια** (που αντιστοιχούν στα 4 νήματα του pipeline):

1. **Ανίχνευση** (Νήμα 1) - Εύρεση στόχων βαθμονόμησης
2. **Ανάλυση** (Νήμα 2) - Εξέταση μεταδεδομένων εικόνας και υπολογισμός βαθμονόμησης
3. **Βαθμονόμηση** (Νήμα 3) - Αποσύνθεση GPU, διόρθωση βινιέτας, υπολογισμός δείκτη
4. **Εξαγωγή** (Νήμα 4) - Αποθήκευση επεξεργασμένων εικόνων και δεικτών**Αλληλεπίδραση με τη γραμμή προόδου:*** **Τοποθετήστε το ποντίκι** πάνω από τη γραμμή για να δείτε το αναπτυσσόμενο πλαίσιο με τις 4 λεπτομερείς φάσεις
* **Κάντε κλικ** στη γραμμή προόδου για να παγώσετε το αναπτυσσόμενο πλαίσιο στη θέση του
* **Κάντε ξανά κλικ** για να ξεπαγώσετε και να αποκρύψετε το πλαίσιο**Χρόνος επεξεργασίας:**

* Σημαντικά ταχύτερος από τη δωρεάν λειτουργία
* Κλιμακώνεται ανάλογα με τον αριθμό πυρήνων της CPU
* Η επιτάχυνση GPU βελτιώνει περαιτέρω την ταχύτητα

{% hint style="info" %}
**Chloros+ Ταχύτητα**: Η παράλληλη επεξεργασία μπορεί να είναι 5-10 φορές ταχύτερη από τη διαδοχική λειτουργία για μεγάλα σύνολα δεδομένων. Ένα έργο 500 εικόνων που διαρκεί 2 ώρες στη δωρεάν λειτουργία μπορεί να ολοκληρωθεί σε 15-20 λεπτά με το Chloros+.
{% endhint %}

## Τι συμβαίνει κατά τη διάρκεια της επεξεργασίας

### Στάδιο 1: Ανίχνευση στόχων

**Τι κάνει το Chloros:**

* Σαρώνει τις επισημασμένες εικόνες-στόχους (ή όλες τις εικόνες αν δεν υπάρχουν επισημασμένες)
* Προσδιορίζει τα 4 πάνελ βαθμονόμησης σε κάθε στόχο
* Εξάγει τιμές ανακλαστικότητας από τα πάνελ στόχων
* Καταγράφει χρονικές σημάνσεις στόχων για τον προγραμματισμό της βαθμονόμησης

**Διάρκεια:** 1-30 δευτερόλεπτα (με επισημασμένους στόχους), 5-30+ λεπτά (χωρίς επισημάνσεις)

### Στάδιο 2: Debayering (Μετατροπή RAW)

**Τι κάνει το Chloros:**

* Μετατρέπει δεδομένα μοτίβου Bayer RAW σε πλήρεις εικόνες RGB
* Εφαρμόζει αλγόριθμο αποσυμπίεσης υψηλής ποιότητας
* Διατηρεί τη μέγιστη ποιότητα εικόνας και λεπτομέρεια

**Διάρκεια:** Διαφέρει ανάλογα με τον αριθμό των εικόνων και την ταχύτητα της CPU

### Στάδιο 3: Βαθμονόμηση

**Τι κάνει το Chloros:*** **Διόρθωση βινιέτας**: Αφαιρεί το σκούρο περίγραμμα στα άκρα
* **Βαθμονόμηση ανακλαστικότητας**: Ομαλοποιεί χρησιμοποιώντας τιμές ανακλαστικότητας στόχου
* Εφαρμόζει διορθώσεις σε όλες τις ζώνες/κανάλια
* Χρησιμοποιεί τον κατάλληλο στόχο βαθμονόμησης για κάθε εικόνα με βάση τη χρονική σήμανση

**Διάρκεια:** Το μεγαλύτερο μέρος του χρόνου επεξεργασίας

### Στάδιο 4: Υπολογισμός δείκτη

**Τι κάνει το Chloros:**

* Υπολογίζει τους διαμορφωμένους πολυφασματικούς δείκτες (NDVI, NDRE, κ.λπ.)
* Εφαρμόζει μαθηματικές πράξεις ζωνών στις βαθμονομημένες εικόνες
* Δημιουργεί εικόνες δείκτη για κάθε επιλεγμένο δείκτη

**Διάρκεια:** Λίγα δευτερόλεπτα ανά εικόνα

### Στάδιο 5: Εξαγωγή

**Τι κάνει το Chloros:**

* Αποθηκεύει τις βαθμονομημένες εικόνες στην επιλεγμένη μορφή
* Εξάγει εικόνες δείκτη με τα διαμορφωμένα χρώματα LUT
* Γράφει αρχεία σε υποφακέλους μοντέλων κάμερας
* Διατηρεί τα αρχικά ονόματα αρχείων με καταλήξεις

**Διάρκεια:** Διαφέρει ανάλογα με τη μορφή εξαγωγής και το μέγεθος του αρχείου***

## Συμπεριφορά επεξεργασίας

### Αυτόματη ροή επεξεργασίας

Μόλις ξεκινήσει, ολόκληρη η ροή εκτελείται αυτόματα:

* Δεν απαιτείται αλληλεπίδραση με τον χρήστη
* Όλα τα διαμορφωμένα βήματα εκτελούνται διαδοχικά
* Οι ενημερώσεις προόδου εμφανίζονται σε πραγματικό χρόνο

### Χρήση υπολογιστή κατά τη διάρκεια της επεξεργασίας

**Λειτουργία Free:**

* Σχετικά χαμηλή χρήση CPU (μονής ροής)
* Ο υπολογιστής παραμένει ανταποκρινόμενος για άλλες εργασίες
* Είναι ασφαλές να ελαχιστοποιήσετε το Chloros και να εργαστείτε σε άλλες εφαρμογές

**Chloros+ Λειτουργία Parallel:**

* Υψηλή χρήση CPU (πολλαπλών ροών, έως 16 πυρήνες)
* Με επιτάχυνση GPU: Υψηλή χρήση GPU
* Ο υπολογιστής ενδέχεται να είναι λιγότερο ανταποκρινόμενος κατά τη διάρκεια της επεξεργασίας
* Αποφύγετε την εκκίνηση άλλων εργασιών που απαιτούν έντονη χρήση της CPU

{% hint style="warning" %}
**Συμβουλή απόδοσης**: Για βέλτιστη απόδοση Chloros+, κλείστε άλλες εφαρμογές και αφήστε το Chloros να χρησιμοποιήσει όλους τους πόρους του συστήματος.
{% endhint %}

### Η επεξεργασία δεν μπορεί να τεθεί σε παύση

**Σημαντικοί περιορισμοί:**

* Μόλις ξεκινήσει, η επεξεργασία δεν μπορεί να τεθεί σε παύση
* Μπορείτε να ακυρώσετε την επεξεργασία, αλλά η πρόοδος χάνεται
* Τα μερικά αποτελέσματα δεν αποθηκεύονται
* Πρέπει να ξεκινήσετε από την αρχή αν ακυρωθεί

**Συμβουλή σχεδιασμού:** Για πολύ μεγάλα έργα, εξετάστε το ενδεχόμενο επεξεργασίας σε παρτίδες ή τη χρήση του CLI για καλύτερο έλεγχο.***

## Παρακολούθηση της επεξεργασίας σας

Κατά τη διάρκεια της επεξεργασίας, μπορείτε:

* **Να παρακολουθήσετε τη γραμμή προόδου** - Δείτε το συνολικό ποσοστό ολοκλήρωσης
* **Να δείτε το τρέχον στάδιο** - Ανίχνευση, Ανάλυση, Βαθμονόμηση ή Εξαγωγή
* **Να ελέγξετε την καρτέλα καταγραφής** - Δείτε λεπτομερή μηνύματα επεξεργασίας και προειδοποιήσεις
* **Να κάνετε προεπισκόπηση των ολοκληρωμένων εικόνων** - Ορισμένα αρχεία εξαγωγής ενδέχεται να εμφανιστούν κατά τη διάρκεια της επεξεργασίας

Για λεπτομερείς πληροφορίες σχετικά με την παρακολούθηση, ανατρέξτε στο [Παρακολούθηση της επεξεργασίας](monitoring-the-processing.md).

## Ακύρωση της επεξεργασίας

Εάν πρέπει να σταματήσετε την επεξεργασία:

### Πώς να ακυρώσετε

1. Εντοπίστε το **κουμπί Διακοπή/Ακύρωση** (αντικαθιστά το κουμπί Έναρξη κατά τη διάρκεια της επεξεργασίας)
2. Κάντε κλικ στο κουμπί Διακοπή
3. Η επεξεργασία διακόπτεται αμέσως
4. Τα μερικά αποτελέσματα απορρίπτονται

### Πότε να ακυρώσετε

**Έγκυροι λόγοι για ακύρωση:**

* Διαπιστώσατε ότι χρησιμοποιήθηκαν λανθασμένες ρυθμίσεις
* Ξεχάσατε να επισημάνετε τις εικόνες-στόχους
* Εισήχθησαν λάθος εικόνες
* Το σύστημα λειτουργεί πολύ αργά ή δεν ανταποκρίνεται

**Μετά την ακύρωση:**

* Ελέγξτε και διορθώστε τυχόν προβλήματα
* Προσαρμόστε τις ρυθμίσεις όπως απαιτείται
* Ξεκινήστε ξανά την επεξεργασία από την αρχή
* Για την καλύτερη δυνατή εμπειρία, κλείστε εντελώς το Chloros και κάντε επανεκκίνηση

{% hint style="warning" %}
**Δεν υπάρχουν μερικά αποτελέσματα**: Η ακύρωση απορρίπτει όλη την πρόοδο. Το Chloros δεν αποθηκεύει εικόνες που έχουν υποστεί μερική επεξεργασία.
{% endhint %}

## Εκτιμήσεις χρόνου επεξεργασίας

Ο πραγματικός χρόνος επεξεργασίας ποικίλλει σημαντικά ανάλογα με:

* Τον αριθμό των εικόνων
* Την ανάλυση των εικόνων
* Τη μορφή εισόδου RAW έναντι JPG
* Τη λειτουργία επεξεργασίας (Δωρεάν έναντι Chloros+)
* Ταχύτητα CPU και αριθμός πυρήνων
* Διαθεσιμότητα GPU (μόνο Chloros+)
* Αριθμός δεικτών προς υπολογισμό
* Πολυπλοκότητα μορφής εξαγωγής

### Κατά προσέγγιση εκτιμήσεις (Chloros+, εικόνες 12MP, σύγχρονη CPU)

| Αριθμός εικόνων | Λειτουργία Free | Chloros+ (CPU) | Chloros+ (GPU) |
| ----------- | --------- | -------------- | -------------- |
| 50 εικόνες   | 15-20 λεπτά | 5-8 λεπτά        | 3-5 λεπτά        |
| 100 εικόνες  | 30-40 λεπτά | 10-15 λεπτά      | 5-8 λεπτά        |
| 200 εικόνες  | 1-1,5 ώρες | 20-30 λεπτά      | 10-15 λεπτά      |
| 500 εικόνες  | 2-3 ώρες   | 45-60 λεπτά      | 20-30 λεπτά      |
| 1000 εικόνες | 4-6 ώρες   | 1,5-2 ώρες      | 40-60 λεπτά      |

{% hint style="info" %}
**Πρώτη εκτέλεση**: Η αρχική επεξεργασία ενδέχεται να διαρκέσει περισσότερο, καθώς το Chloros δημιουργεί προσωρινά αρχεία και προφίλ. Η επόμενη επεξεργασία παρόμοιων συνόλων δεδομένων θα είναι ταχύτερη.
{% endhint %}

## Συχνά προβλήματα κατά την εκκίνηση

### Το κουμπί εκκίνησης είναι απενεργοποιημένο (απαλό)

**Πιθανές αιτίες:**

* Δεν έχουν εισαχθεί εικόνες
* Το backend δεν έχει ξεκινήσει πλήρως
* Η προηγούμενη επεξεργασία εξακολουθεί να εκτελείται
* Το έργο δεν έχει φορτωθεί πλήρως

**Λύσεις:**

1. Περιμένετε μέχρι να ολοκληρωθεί η αρχικοποίηση του backend (ελέγξτε το εικονίδιο του κύριου μενού)
2. Βεβαιωθείτε ότι οι εικόνες έχουν εισαχθεί στο File Browser
3. Επανεκκινήστε το Chloros εάν το κουμπί παραμένει απενεργοποιημένο
4. Ελέγξτε το Debug Log για μηνύματα σφάλματος

### Η επεξεργασία ξεκινά και αμέσως αποτυγχάνει

**Πιθανές αιτίες:**

* Δεν υπάρχουν έγκυρες εικόνες στο έργο
* Κατεστραμμένα αρχεία εικόνων
* Ανεπαρκής χώρος στο δίσκο
* Ανεπαρκής μνήμη (RAM)

**Λύσεις:**

1. Ελέγξτε το αρχείο καταγραφής σφαλμάτων <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> για μηνύματα σφάλματος
2. Επαληθεύστε τον διαθέσιμο χώρο στο δίσκο
3. Δοκιμάστε να επεξεργαστείτε ένα μικρότερο υποσύνολο εικόνων
4. Επαληθεύστε ότι οι εικόνες δεν είναι κατεστραμμένες

### Προειδοποίηση «Δεν εντοπίστηκαν στόχοι»

**Πιθανές αιτίες:**

* Ξεχάσατε να επισημάνετε τις εικόνες-στόχους
* Οι εικόνες-στόχοι δεν περιέχουν ορατούς στόχους
* Οι ρυθμίσεις ανίχνευσης στόχων είναι πολύ αυστηρές

**Λύσεις:**

1. Ανατρέξτε στο [Επιλογή εικόνων-στόχων](choosing-target-images.md)
2. Επισημάνετε τις κατάλληλες εικόνες στη στήλη «Στόχος»
3. Βεβαιωθείτε ότι οι στόχοι είναι ορατοί στις επισημασμένες εικόνες
4. Προσαρμόστε τις ρυθμίσεις ανίχνευσης στόχων, αν χρειαστεί

## Συμβουλές για επιτυχή επεξεργασία

### Πριν ξεκινήσετε

1. **Δοκιμάστε πρώτα με ένα μικρό υποσύνολο** - Επεξεργαστείτε 10-20 εικόνες για να επαληθεύσετε τις ρυθμίσεις
2. **Ελέγξτε τον διαθέσιμο χώρο στο δίσκο** - Βεβαιωθείτε ότι υπάρχει ελεύθερος χώρος 2-3 φορές μεγαλύτερος από το μέγεθος του συνόλου δεδομένων
3. **Κλείστε τις περιττές εφαρμογές** - Απελευθερώστε πόρους του συστήματος
4. **Επαληθεύστε τις εικόνες-στόχους** - Προβάλετε τους επισημασμένους στόχους για να βεβαιωθείτε για την ποιότητα
5. **Αποθηκεύστε το έργο** - Το έργο αποθηκεύεται αυτόματα, αλλά συνιστάται να το αποθηκεύετε χειροκίνητα

### Κατά τη διάρκεια της επεξεργασίας

1. **Αποφύγετε την κατάσταση αναστολής λειτουργίας του συστήματος** - Απενεργοποιήστε τις λειτουργίες εξοικονόμησης ενέργειας
2. **Διατηρήστε το Chloros στο προσκήνιο** - Ή τουλάχιστον ορατό στη γραμμή εργασιών
3. **Παρακολουθήστε την πρόοδο περιστασιακά** - Ελέγξτε για προειδοποιήσεις ή σφάλματα
4. **Μην φορτώνετε άλλες βαριές εφαρμογές** - Ειδικά με την παράλληλη λειτουργία του Chloros+

### Επιτάχυνση GPU του Chloros+

Εάν χρησιμοποιείτε επιτάχυνση GPU της NVIDIA:

1. Ενημερώστε τα προγράμματα οδήγησης της NVIDIA στην πιο πρόσφατη έκδοση
2. Βεβαιωθείτε ότι η GPU διαθέτει 4 GB+ VRAM
3. Κλείστε εφαρμογές που απαιτούν έντονη χρήση της GPU (παιχνίδια, επεξεργασία βίντεο)
4. Παρακολουθήστε τη θερμοκρασία της GPU (βεβαιωθείτε ότι υπάρχει επαρκής ψύξη)
