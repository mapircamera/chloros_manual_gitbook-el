# Επισκόπηση Linux

Το Chloros 1.3.0 παρέχει εγγενή υποστήριξη Linux για το **CLI**και το**Python SDK** — επεξεργασία πολυφασματικών εικόνων χωρίς οθόνη, καθώς και ζωντανό έλεγχο καμερών LATTICE και αισθητήρων φωτός DAQ — σε σταθμούς εργασίας Linux, διακομιστές και συσκευές περιφέρειας NVIDIA Jetson.

{% hint style="info" %}
**Δεν υπάρχει γραφικό περιβάλλον εργασίας (GUI) για Linux.**Το γραφικό περιβάλλον εργασίας του Chloros είναι διαθέσιμο μόνο για Windows. Οι χρήστες Linux αλληλεπιδρούν με το Chloros μέσω της [CLI](../CLI.md) και του [Python SDK](../api-python-sdk.md). Το `.deb` προσθέτει πράγματι μια καταχώριση**Chloros CLI** στο μενού εφαρμογών σας — απλώς ανοίγει έναν εξομοιωτή τερματικού που εκτελεί το `chloros-cli`.
{% endhint %}

## Υποστηριζόμενες αρχιτεκτονικές

| Αρχιτεκτονική | Περιγραφή | Πακέτο |
| --- | --- | --- |
| **amd64 (x86_64)** | Τυπικοί επεξεργαστές επιτραπέζιων υπολογιστών/διακομιστών (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Επεξεργαστές ARM — Οικογένεια NVIDIA Jetson Orin (JetPack 6) | `chloros_<version>_arm64_jp6.deb` |

## Υποστηριζόμενες διανομές Linux

* **Ubuntu 22.04 LTS ή νεότερη έκδοση** (amd64)
* **Debian 12 ή νεότερη έκδοση** (amd64)
* **NVIDIA JetPack 6** (arm64 — πλατφόρμες Jetson Orin)

## Τι προσφέρεται στους χρήστες Linux

* **Chloros CLI** — η πλήρης διεπαφή γραμμής εντολών για μαζική επεξεργασία, αυτοματοποίηση και δημιουργία σεναρίων
* **Chloros Python SDK** — προγραμματιστική διεπαφή Python για ερευνητικές ροές εργασιών και προσαρμοσμένα εργαλεία, η οποία εγκαθίσταται από το `.deb` για το σύστημα `python3` (ένα wheel συμβατό με την έκδοση για virtualenvs βρίσκεται στο `/usr/lib/chloros/sdk/`· το PyPI προορίζεται για μηχανές χωρίς πακέτο Chloros)
* **Έλεγχος καμερών LATTICE** — εντοπισμός, σύνδεση, διαμόρφωση και καταγραφή από κάμερες LATTICE και συγχρονισμένες συστοιχίες πολλαπλών καμερών μέσω του `chloros-cli lattice` και του SDK· το `.deb` περιλαμβάνει το περιβάλλον εκτέλεσης του Arena SDK που απαιτούν οι κάμερες
* **Έλεγχος αισθητήρων φωτός DAQ** — συνδέστε αισθητήρες DAQ-U/M/E, μεταδώστε βαθμονομημένα φάσματα και καταγράψτε αρχεία `.daq` μέσω του `chloros-cli daq pool-*` και του SDK
* **Συγχρονισμός χρόνου PTP** — το backend του Chloros εκτελεί τον grandmaster PTP στον οποίο υποτάσσονται οι κάμερες LATTICE και οι αισθητήρες DAQ-E· ελέγξτε τον με το `chloros-cli time-sync` και διατηρήστε τον σε λειτουργία χωρίς οθόνη με τη μονάδα systemd `chloros-backend@<user>.service` (βλ. [Εγκατάσταση σε Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Αυτοματοποίηση έργων** — εκτελέστε αποθηκευμένα έργα χωρίς οθόνη με το `chloros-cli project` και το `open_project` του SDK
* **Επιτάχυνση GPU** — Επεξεργασία επιταχυνόμενη από CUDA σε GPU της NVIDIA (GPU επιτραπέζιων υπολογιστών σε amd64 και η GPU του Jetson με το JetPack 6)
* **Δυναμική προσαρμογή υπολογισμών** — αυτόματη ανίχνευση υλικού και επιλογή στρατηγικής επεξεργασίας, με την παράκαμψη `CHLOROS_STRATEGY` ως «εξόδου διαφυγής» για ειδικούς
* **Όλες οι λειτουργίες επεξεργασίας** — ο ίδιος αγωγός επεξεργασίας με τα Windows: βαθμονόμηση, διόρθωση βινιέτας, δείκτες βλάστησης και κάθε μορφή εξαγωγής
* **Λειτουργίες Chloros+** — επεξεργασία πολλαπλών νημάτων (σε σειρά), αποσυμπίεση με αναγνώριση υφής (Texture Aware debayer) (σε GPU CUDA) και προσαρμοσμένοι δείκτες, με συνδρομητικό πακέτο Chloros+

## Τι δεν έχουν οι χρήστες Linux

* **Γραφικό περιβάλλον εργασίας (GUI)** — δεν υπάρχει γραφικό περιβάλλον εργασίας· όλη η αλληλεπίδραση γίνεται μέσω CLI ή Python SDK
* **Πρόγραμμα προβολής εικόνων** — δεν υπάρχει διαδραστικό πρόγραμμα προβολής εικόνων, προβολή πλέγματος ή δείκτες χάρτη
* **Οπτική διαχείριση έργων** — τα έργα δημιουργούνται και εκτελούνται μέσω εντολών CLI και κλήσεων SDK (το ίδιο το υλικό — κάμερες, αισθητήρες, καταγραφή — παραμένει πλήρως ελεγχόμενο από το τερματικό)

## Απαιτήσεις άδειας χρήσης

Η πρόσβαση στο CLI και στο SDK απαιτεί **πληρωμένο πακέτο Chloros+ — Copper ή ανώτερο**(Copper, Bronze, Silver, Gold). Το δωρεάν πακέτο**Iron** δεν παρέχει πρόσβαση στο CLI/SDK. Ο περιορισμός επιβάλλεται από το backend, όχι μόνο από το CLI:

| Κατάσταση | Απόκριση backend |
| --- | --- |
| Δεν έχετε συνδεθεί | `401` με `error_code: AUTH_REQUIRED` |
| Συνδεδεμένος στο δωρεάν επίπεδο Iron | `403` με `error_code: PLAN_UPGRADE_REQUIRED` |

Το `chloros-cli status` λειτουργεί σε οποιοδήποτε επίπεδο — είναι η μόνη διαδρομή που εξαιρείται από τον έλεγχο — οπότε ο λόγος απόρριψης είναι πάντα ορατός.

## Ξεκινώντας στο Linux

1. **Εγκατάσταση του Chloros** — δείτε την [Εγκατάσταση σε Linux](linux-installation.md) για την εγκατάσταση του `.deb`
2. **Επαλήθευση** — το `chloros-cli --version` εμφανίζει το `Chloros CLI 1.3.0`· το `chloros-cli selftest` εκτελεί τη διάγνωση 7 βημάτων
3. **Ελέγξτε το Python SDK** — το `.deb` το εγκαθιστά: `python3 -c "import chloros_sdk; print(chloros_sdk.__version__)"` (σε ένα virtualenv, `pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl`)
4. **Συνδεθείτε** — `chloros-cli login your@email.com 'your-password'` (μία φορά ανά υπολογιστή· οι αναβαθμίσεις του πακέτου διατηρούν τα στοιχεία σύνδεσης, ενώ η κατάργηση του πακέτου τα διαγράφει)
5. **Επεξεργαστείτε το πρώτο σας σύνολο δεδομένων** — `chloros-cli process ~/datasets/flight001`

Για το NVIDIA Jetson, ανατρέξτε στον ειδικό [Οδηγό NVIDIA Jetson](nvidia-jetson-guide.md) για ρυθμίσεις ειδικές για την πλατφόρμα, θερμική συμπεριφορά και ανάπτυξη στο πεδίο.
