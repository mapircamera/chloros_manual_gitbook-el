# Linux Επισκόπηση

Η έκδοση Chloros 1.1.0 προσφέρει εγγενή υποστήριξη Linux για τα **CLI**και**Python SDK**, επιτρέποντας την επεξεργασία πολυφασματικών εικόνων χωρίς οθόνη σε σταθμούς εργασίας, διακομιστές και συσκευές NVIDIA Jetson edge.

{% hint style="info" %}
**Δεν υπάρχει GUI στο Linux.** Το GUI του Chloros Desktop είναι διαθέσιμο μόνο στο Windows. Οι χρήστες του Linux αλληλεπιδρούν με το Chloros μέσω του [CLI](../CLI.md) και του [Python SDK](../api-python-sdk.md).
{% endhint %}

***

## Πίνακας υποστήριξης πλατφορμών

| Λειτουργία | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **GUI επιφάνειας εργασίας** | Ναι | Δεν ισχύει | Όχι | Όχι |
| **CLI** | Ναι | Ναι | Ναι | Ναι |
| **Python SDK** | Ναι | Ναι | Ναι | Ναι |
| **Επιτάχυνση GPU (CUDA)** | Ναι | Ναι | Ναι | Ναι (JetPack 6) |
| **Texture Aware Debayer** | Ναι (Chloros+) | Ναι (Chloros+) | Ναι (Chloros+) | Ναι (Chloros+) |
| **Δυναμική προσαρμογή υπολογισμών** | Ναι | Ναι | Ναι | Ναι |***

## Υποστηριζόμενες αρχιτεκτονικές

| Αρχιτεκτονική | Περιγραφή | Μέθοδος εγκατάστασης |
| --- | --- | --- |
| **amd64 (x86_64)** | Τυπικοί επεξεργαστές επιτραπέζιων υπολογιστών/διακομιστών (Intel, AMD) | Πακέτο `.deb` |
| **arm64 (aarch64)** | Επεξεργαστές βασισμένοι σε ARM, κυρίως NVIDIA Jetson | Πακέτο `.deb` (JetPack 6) |

## Υποστηριζόμενες διανομές Linux

* **Ubuntu 20.04+** (amd64)
* **Debian 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — πλατφόρμες Jetson)***

## Τι λαμβάνουν οι χρήστες του Linux

* **Chloros CLI** — Πλήρης διεπαφή γραμμής εντολών για μαζική επεξεργασία, αυτοματοποίηση και δημιουργία σεναρίων
* **Chloros Python SDK** — Προγραμματιστική διεπαφή Python (`pip install chloros-sdk`) για ενσωμάτωση σε ερευνητικές ροές εργασίας και προσαρμοσμένα εργαλεία
* **Επιτάχυνση GPU** — Επεξεργασία επιταχυνόμενη από CUDA σε GPU NVIDIA (επιτραπέζιους υπολογιστές και Jetson)
* **Δυναμική προσαρμογή υπολογισμών** — Αυτόματη ανίχνευση υλικού και βελτιστοποίηση στρατηγικής επεξεργασίας
* **Όλες οι λειτουργίες επεξεργασίας** — Ίδια ροή επεξεργασίας πολυφασματικών δεδομένων με το Windows (βαθμονόμηση, διόρθωση βινιέτας, δείκτες βλάστησης, όλες οι μορφές εξαγωγής)
* **Λειτουργίες Chloros+** — Επεξεργασία πολλαπλών νημάτων, Texture Aware debayer, προσαρμοσμένοι δείκτες (με άδεια Chloros+)

## Τι δεν έχουν οι χρήστες του Linux

* **GUI επιφάνειας εργασίας** — Χωρίς γραφικό περιβάλλον εργασίας· όλη η αλληλεπίδραση γίνεται μέσω του CLI ή του Python SDK
* **Πρόγραμμα προβολής εικόνων** — Δεν υπάρχει διαδραστικό πρόγραμμα προβολής εικόνων, προβολή πλέγματος ή δείκτες χάρτη
* **Οπτική διαχείριση έργων** — Τα έργα διαχειρίζονται μέσω εντολών CLI και κλήσεων SDK***

## Ξεκινώντας με το Linux

1. **Εγκατάσταση του Chloros** — Ανατρέξτε στην [Εγκατάσταση του Linux](linux-installation.md) για την εγκατάσταση του πακέτου `.deb`
2. **Εγκαταστήστε το Python SDK** (προαιρετικό) — `pip install chloros-sdk`
3. **Ενεργοποιήστε την άδειά σας** — `chloros-cli login your@email.com 'password'`
4. **Επεξεργαστείτε το πρώτο σας σύνολο δεδομένων** — `chloros-cli process ~/datasets/flight001`

Για χρήστες NVIDIA Jetson, ανατρέξτε στον ειδικό [Οδηγό NVIDIA Jetson](nvidia-jetson-guide.md) για ρύθμιση και βελτιστοποίηση ειδικά για την πλατφόρμα.
