# Linux – Επισκόπηση

Το Chloros 1.2.0 παρέχει εγγενή υποστήριξη Linux για τα **CLI**και**Python SDK** — επεξεργασία πολυφασματικών εικόνων χωρίς οθόνη, καθώς και ζωντανό έλεγχο καμερών LATTICE και αισθητήρων φωτός DAQ — σε σταθμούς εργασίας, διακομιστές και συσκευές ακμής NVIDIA Jetson.

{% hint style="info" %}
**Δεν υπάρχει γραφικό περιβάλλον εργασίας (GUI) για επιτραπέζιους υπολογιστές στο Linux.**Το γραφικό περιβάλλον εργασίας (GUI) για επιτραπέζιους υπολογιστές Chloros διατίθεται αποκλειστικά για το Windows. Οι χρήστες του Linux αλληλεπιδρούν με το Chloros μέσω του [CLI](../CLI.md) και [Python SDK](../api-python-sdk.md). Το `.deb` προσθέτει πράγματι μια**Chloros CLI** στο μενού της εφαρμογής σας — απλώς ανοίγει έναν εξομοιωτή τερματικού που εκτελεί το `chloros-cli`.
{% endhint %}

## Υποστηριζόμενες αρχιτεκτονικές

| Αρχιτεκτονική | Περιγραφή | Πακέτο |
| --- | --- | --- |
| **amd64 (x86_64)** | Τυπικοί επεξεργαστές επιτραπέζιων υπολογιστών/διακομιστών (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Επεξεργαστές ARM — Οικογένεια NVIDIA Jetson Orin | `chloros_<version>_arm64_jp6.deb` (έκδοση JetPack 6) |

## Υποστηριζόμενες διανομές Linux

* **Ubuntu 22.04 LTS ή νεότερη έκδοση** (amd64)
* **Debian 12 ή νεότερη έκδοση** (amd64)
* **NVIDIA JetPack 6** (arm64 — πλατφόρμες Jetson Orin)***

## Τι προσφέρει το Linux στους χρήστες

* **Chloros CLI** — η πλήρης διεπαφή γραμμής εντολών για μαζική επεξεργασία, αυτοματοποίηση και δημιουργία σεναρίων
* **Chloros Python SDK** — προγραμματιστική διεπαφή Python για ερευνητικές ροές εργασιών και προσαρμοσμένα εργαλεία (εγκαθίσταται από το PyPI, ενώ περιλαμβάνεται και στο `.deb` ως wheel συμβατό με την έκδοση)
* **Έλεγχος καμερών LATTICE** — εντοπισμός, σύνδεση, διαμόρφωση και καταγραφή από κάμερες LATTICE και συγχρονισμένα συστοιχία πολλαπλών καμερών μέσω των `chloros-cli lattice` και SDK· το `.deb` περιλαμβάνει το περιβάλλον εκτέλεσης Arena SDK που απαιτούν οι κάμερες
* ****Έλεγχος αισθητήρων φωτός DAQ** — συνδέστε αισθητήρες DAQ-U/M/E, μεταδώστε βαθμονομημένα φάσματα και καταγράψτε αρχεία `.daq` μέσω των `chloros-cli daq pool-*` και SDK
* **Συγχρονισμός χρόνου PTP** — το backend Chloros εκτελεί τον grandmaster PTP στον οποίο υποτάσσονται οι κάμερες LATTICE και οι αισθητήρες DAQ-E· ελέγξτε το με το `chloros-cli time-sync`, και διατηρήστε το σε λειτουργία χωρίς οθόνη μέσω της μονάδας systemd `chloros-backend.service` (βλ. [Εγκατάσταση Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Αυτοματοποίηση έργων** — εκτελέστε αποθηκευμένα έργα χωρίς διεπαφή χρήστη με το `chloros-cli project` και το `open_project` του SDK
* **Επιτάχυνση GPU** — Επεξεργασία επιταχυνόμενη από CUDA σε GPU της NVIDIA (επιτραπέζιες και Jetson)
* **Δυναμική προσαρμογή υπολογιστικής ισχύος** — Αυτόματη ανίχνευση υλικού και επιλογή στρατηγικής επεξεργασίας, με την παράκαμψη `CHLOROS_STRATEGY` ως «εξόδου διαφυγής» για ειδικούς
* **Όλες οι λειτουργίες επεξεργασίας** — ο ίδιος αγωγός επεξεργασίας με το Windows: βαθμονόμηση, διόρθωση βινιέτας, δείκτες βλάστησης και όλες οι μορφές εξαγωγής
* **Λειτουργίες του Chloros+** — επεξεργασία πολλαπλών νημάτων (σε σειρά), αποσυμπίεση εικόνας με αναγνώριση υφής (Texture Aware debayer) και προσαρμοσμένοι δείκτες, με ένα πρόγραμμα Chloros+ επί πληρωμή

## Τι δεν έχουν οι χρήστες του Linux

* **Γραφικό περιβάλλον εργασίας (GUI)** — δεν υπάρχει γραφικό περιβάλλον εργασίας· όλη η αλληλεπίδραση γίνεται μέσω του CLI ή του Python SDK
* **Πρόγραμμα προβολής εικόνων** — δεν υπάρχει διαδραστικό πρόγραμμα προβολής εικόνων, προβολή πλέγματος ή δείκτες χάρτη
* **Οπτική διαχείριση έργων** — τα έργα δημιουργούνται και εκτελούνται μέσω εντολών CLI και κλήσεων SDK (το ίδιο το υλικό — κάμερες, αισθητήρες, καταγραφή — παραμένει πλήρως ελεγχόμενο από το τερματικό)***

## Απαιτήσεις άδειας χρήσης

Η πρόσβαση σε CLI και SDK απαιτεί **επί πληρωμή επίπεδο Chloros+ — Copper ή υψηλότερο**(Copper, Bronze, Silver, Gold). Το δωρεάν επίπεδο**Iron** δεν παρέχει πρόσβαση στις λειτουργίες CLI/SDK. Ο περιορισμός αυτός επιβάλλεται από το backend, όχι μόνο από το CLI:

| Κατάσταση | Απόκριση του backend |
| --- | --- |
| Δεν έχεις συνδεθεί | `401` με `error_code: AUTH_REQUIRED` |
| Συνδεδεμένος στο δωρεάν επίπεδο Iron | `403` με `error_code: PLAN_UPGRADE_REQUIRED` |

Το `chloros-cli status` λειτουργεί σε οποιοδήποτε επίπεδο — είναι η μόνη διαδρομή που εξαιρείται από το φράγμα — οπότε ο λόγος της απόρριψης είναι πάντα ορατός.

## Ξεκινώντας με το Linux

1. **Εγκαταστήστε το Chloros** — ανατρέξτε στην [Εγκατάσταση του Linux](linux-installation.md) για την εγκατάσταση του `.deb`
2. **Επαλήθευση** — Το `chloros-cli --version` εκτυπώνει το `Chloros CLI 1.2.0`· το `chloros-cli selftest` εκτελεί τη διάγνωση 7 βημάτων
3. **Εγκαταστήστε το Python SDK** (προαιρετικά) — `pip install chloros-sdk`
4. **Συνδεθείτε** — `chloros-cli login your@email.com 'your-password'` (μία φορά ανά μηχανή και ξανά μετά από κάθε αναβάθμιση πακέτου)
5. **Επεξεργαστείτε το πρώτο σας σύνολο δεδομένων** — `chloros-cli process ~/datasets/flight001`

Για το NVIDIA Jetson, ανατρέξτε στον ειδικό [Οδηγό NVIDIA Jetson](nvidia-jetson-guide.md) για ρυθμίσεις ειδικές για την πλατφόρμα, θερμική συμπεριφορά και ανάπτυξη στο πεδίο.
